# 드랍 볼트 — 무엇이 어디서 얼마나 떨어지나

드랍 표는 따로 없다. 괴물 정의의 `Drops`·`LootType` 과 `Formulas/monsterexp.cs` 식이 합쳐진 것이 드랍 표다 — 이 볼트는 그것을 한 번 계산해 둔 것이다. 낡으면 `python3 scripts/build-drop-vault.py` 로 다시 만든다.
