# 자료가 어디서 오는가

**판단 절차**

1. **하데스에 데이터가 있으면 하데스다.** 팩으로 **덮지 않는다** — 파일이든 식이든 기본값이든.
2. **없을 때만** 팩을 본다.
3. **그때도 팩 2개가 일치할 때만** 후보다. 불일치하면 **버린다**.

손으로 적은 표는 틀린다. 전에 "아이템: Hades 3 · 팩 989" 라고 적어 뒀는데 하데스
메타파일에 2,110개가 있었다. 그래서 이 볼트는 **셈을 매번 다시 한다.**
