i = 숫자
s = 글자
is = 숫자&글자

#스킬 s = 스킬을 생성한다.
#스킬지우기 s = 스킬을 스킬창에서 지운다.
#스펠 s = 스펠을 생성한다.
#스펠지우기 s = 스펠을 스펠창에서 지운다.
#상태 i = 상태를 변화시킨다.
#바디 i = 바디를 변화시킨다. *(0 = 투명 16 = 남자몸 32 = 여자몸)*
#출두 is = 상대방에게로 간다.
#소환 is = 상대방을 내가있는대로 대리고온다.
#속도 i = 이동속도를 변화시키는거지만, 작동을안한다.
#킬 is = 대상을 팅기게 한다.
#머리 i = 숫자에대응하는 머리스타일로 바뀐다. *(255번머리는 서버구동기를 튕기게한다.)*
#피케이 i = 피케이 여부를 바꾼다. 1 가능 2불가능
#길드 i = 길드가입여부를 사용할때하는 명령어다. *(1 = 길드있음 0 = 길드없음)*
#갑옷 i = 숫자에대응하는 갑옷이미지로 바꾼다. *(아무갑옷이나 착용하고사용한다.)*
#무기 i = 숫자에대응하는 무기이미지로 바꾼다. *(아무무기나 착용하고사용한다.)*
#방패 i = 숫자에대응하는 방패이미지로 바꾼다. *(아무방패나 착용하고사용한다.)*
#성별 i = 성별을 바꾼다. *(1 = 남자 2 = 여자)*
#머리염색 i = 숫자에대응하는 머리색깔로 염색한다.
#이펙트 i = 숫자에대응하는 이펙트를 본다.*(자신한테만 보임)*
#사운드 i = 숫자에대응하는 사운드를 들어본다. *(자신한테만 들림)*
#레벨 i = 숫자에대응하는 레벨로 바꾼다. *(최대 99)*
#어빌 i = 숫자에대응하는 어빌로 바꾼다. *(최대 100)*
#직업 i = 숫자에대응하는 직업으로 바꾼다. *(1 = 전사 2 = 도적 3 = 마법사 4 = 성직자 5 = 무도가)*
#공지 is = 공지사항을 날린다.
#체력 i = 자신의 체력을 변화시킨다. *(최대 = 아이템이올려주는체력 + 명령어로바꾼체력 = 999999999)*
#마나 i = 자신의 마력을 변화시킨다. *(최대 = 아이템이올려주는마력 + 명령어로바꾼마력 = 999999999)*
#힘 i = 힘을 변화시킨다. *(200까지만 하는게 좋다.)*
#인트 i = 인트를 변화시킨다. *(200까지만 하는게 좋다.)*
#위즈 i = 위즈를 변화시킨다. *(200까지만 하는게 좋다.)*
#콘 i = 콘을 변화시킨다. *(200까지만 하는게 좋다.)*
#덱스 i = 덱스를 변화시킨다. *(200까지만 하는게 좋다.)* 
#승급 i = 숫자에대응하는 승급번호로 바꾼다.
#몹소환 is = 몬스터를 소환한다.
#엔피시 is = 엔피시를 소환한다.
#돈 i = 자기밑에 골드를 숫자만큼 떨어뜨린다.
#포인트 i = 자신의 능력치포인트를 대입한다.
#생성 is = 아이템을 생성한다.
#밴 is = is에 해당하는 유저를 밴시킨다.
#언밴 is = is에 해당하는 유저의 밴을 해제한다.
