# server-packs — 원작 계열 서버·클라이언트 팩 (UTF-8 변환본)

배포된 어둠의 전설 계열 팩 3개에서 **텍스트 파일만** 꺼내 CP949 → UTF-8 로 바꾼 것.
원작이 아이템·기술·맵을 어떤 수치로 굴렸는지 찾을 때 읽는다.

| 폴더 | 출처 zip | 텍스트 |
|---|---|---|
| `5.99-server/` | `5.99 서버팩.zip` (3,270 엔트리) | 238 |
| `5.99-client/` | `5.99 클라이언트.zip` (594 엔트리) | 8 |
| `honden-community/` | `혼든커뮤니티팩2.zip` (3,193 엔트리) | 1,143 |

## 알아둘 것
- **텍스트만 있다.** 바이너리(`.map` 5,017개, `.dat` 532MB, `.mus`, `.exe`, `.dll`)는 옮기지 않았다.
  변환하면 깨지고 용량만 먹는다. 필요하면 원본 zip 에서 다시 꺼낸다.
- **원본은 CP949 다.** zip 안 파일명·내용 모두 CP949 이고 UTF-8 플래그가 없어,
  macOS `unzip` 으로 그냥 풀면 파일명이 깨진다. 여기 있는 것은 이미 고친 사본이다.
- **서버 실행에는 이걸 쓰지 마라.** `Novaonline.exe` / `Yuki.exe` 는 CP949 로 읽도록 만들어졌다.
  돌려볼 때는 원본 zip 을 CP949 그대로 풀어서 쓴다.
- 줄바꿈은 원본 그대로(CRLF) 뒀다.

## 어디에 뭐가 있나
- 아이템 수치: `*/db/item/**/*.txt` — 이름·타입·이미지·내구력·방어력·능력치 변화
- 기술·마법: `*/db/skill/`, `*/db/Learn_db.txt`
- 맵·워프: `*/db/maps/*.txt`
