# 위판과머리위둘다그린다

## 규칙

**머리 위 = 백분율 막대(맞을 때만), 위 판 = 채워지는 막대 + 정확한 숫자(늘)**

## 왜

전에는 위 판을 숫자만 남겼으나(2faede52), 사용자가 위 판에도 막대를 다시 요구했다(2026-09-25). 위 판은 항상 · 머리 위는 맞을 때만이라 겹치지 않는다
