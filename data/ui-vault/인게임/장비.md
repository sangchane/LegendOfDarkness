## 원작 그림 통째로

equip01(292x308)을 비율 그대로 줄여 쓰되, 모바일 공간에 필요 없는 부분은 잘라 낸다(사용자 2026-09-30). 잘라 낼 것: 왼쪽 바깥 쇠고리 둘 · 위쪽 이름·칭호 칸 줄(위 판에 있다). 남길 것: 인형 실루엣·장비 칸·AC·DMG·HIT · 왼쪽 아래 Next Lev(다음 레벨까지 남은 경험치 — ExperienceGauge 의 남은 양을 숫자로) · 오른쪽 아래 사람 단추(사용자 2026-09-30: 그룹 받기 켜고 끄기 — 사람 하나 = 신청 거절, 둘 = 신청하면 바로 들어옴. 서버 0x2F 는 돌아가고 모바일은 아직 안 보낸다 → 이 단추가 보내게 한다). 인형 왼쪽 위 책 단추(사용자 2026-09-30: 레전드 기록 — 퀘스트·캐릭터 생성 연도 같은 이벤트를 적는 일기장. 서버는 0x2D 내 프로필 열기 → 0x39 로 레전드 마크를 보낸다, 모바일은 안 읽는다 → 이 단추가 목록 창을 연다). 자를 영역은 그림에서 재서 한 장으로 보여 주고 사용자 확인 뒤 정한다. 장비 아이콘·AC·DMG·HIT·다음 레벨 숫자는 그림의 어두운 칸 자리에 얹는다 — 칸 자리는 그림에서 잰다(원작은 실행 파일 안에 있다). 칸이 48dp 보다 작아지면 누르는 곳만 칸보다 넓게 잡는다
