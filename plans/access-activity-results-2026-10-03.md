## 만든 기능
`https://lodgame.duckdns.org/?view=activity` → 기존 관리자 로그인 필요.
웹 접속 환경(IP·브라우저/수집기·시각), 다운로드 파일/전송량, 날짜별 집계, 캐릭터 로그인/로그아웃·종료 세션 시간·맵·기술/마법/아이템/NPC/상점/교환/동료 요청, 처치/교환 처리 및 경험치·금화 순변화.
캐릭터에 이미 남아 있는 레벨·경험치·금화·괴물별 누적 처치는 기간 통계와 별도로 표시. Monk5 저장 자료: 47레벨, 괴물 40종/누적 1,456회(확인 시점).

웹 JSON 로그는 nginx의 request_id, 게임 JSONL은 서버 인증 계정/세션 기준. 앱 재설치 불필요. 30초마다 SQLite에 증가분 수집, 한국 시각 날짜·90일 보관, 상세 각각 최근 200행(날짜/캐릭터로 조회). 게임 요청은 최대 60초 구간으로 묶고 강제 종료 직전 구간은 빠질 수 있다. 요청과 성공 결과 구분. 비밀번호/채팅/원시 패킷 제외. 웹 쿼리 문자열 제외.

## 검증·리뷰
- Python 전체 96 통과, 대시보드 JS 32 통과. HTTP API 비인증 401/잘못된 기간 400, HEAD/부분 줄/회전 중복/봇/누적 allowlist 확인.
