# 접속 유저창 — SPEC (M, 2026-10-04)

## 문제·성공 기준
지금 누가 접속해 있는지 볼 수 없다. 위 메뉴 [접속자] → 원작 사람 목록 창(`users01`)이 뜨고, 줄마다 **직업 마크 + 아이디**.
정렬: 레벨 높은 순, 같으면 최대 체력 + 최대 마력×2 큰 순(사용자).

## 근거
- 서버에 이미 있다: 0x18(몸 없음) → 0x36 `ServerFormat36` — `[u16 total][u16 count]` 뒤 사람마다
  `[직업|0x88][색][상태][칭호?][단계?][이름 StringA]`. 정렬은 체력+마력×2 하나뿐 → 레벨 먼저로 바꾼다.
- 원작 그림: `users01`(466×308 — 왼쪽 어두운 목록 두 칸 26~159 · 166~250, y 22~276 / 오른쪽 Total·직업별 칸 x 374~437),
  `legends`(직업 아이콘 20×20 여덟, 24px 간격: 농부·전사·도적·마법사·성직자·무도가·…).

## 만들 것
1. 서버 `ServerFormat36`: `OrderByDescending(레벨).ThenByDescending(체력+마력×2)`.
2. 알맹이 `UserList.Read` (0x36 해석, 직업 = 첫 바이트 & 0x07) · `AskUsersAsync`(0x18) · `TakeUsers()`. 시험 1개.
3. 화면 `UsersPanel`: `users01` 통째 축소(화면에 맞게, 1배 넘지 않음), 왼쪽 목록 칸에 2열 줄(누끼 아이콘 + 아이디), 넘치면 굴림.
   오른쪽 칸: Total·직업별 수(원작 칸을 비워 두지 않으려고). 제목 판 「접속자」, 오른쪽 위 X.
4. 위 메뉴 [접속자] 단추(아이콘 = legends 첫 그림) — 누를 때마다 0x18 을 보내 새로 받는다.

## 안 할 것
길드·칭호·색·상태 표시, 귓속말·누르면 장비창, 자동 새로고침.

## 완료 기준
- 알맹이 시험 통과(정렬된 두 사람 패킷 → 직업·이름) · 서버 빌드 · 앱 빌드 · LayoutCheck 통과
- 로컬 서버 로그인 화면 사진 한 장(창이 뜨고 이름이 보임)
