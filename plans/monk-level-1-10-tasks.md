# 무도가 1–10레벨 기술 작업

1. [완료/테스트 우선] 진행선 템플릿과 스크립트 연결을 검증하는 실패 테스트를 작성한다.
   - 완료 기준: 현재 빈 `ScriptName` 때문에 테스트가 실패한다.
2. [완료/테스트 우선] 우드랜드1-1의 고정 표적에 기술 5개를 사용하는 통합 테스트를 작성한다.
   - 완료 기준: 빈 스크립트 기술이 체력 보고를 만들지 못해 실패한다.
3. [완료] Hades 패턴을 따르는 공통 무도가 앞칸 공격과 네 기술 스크립트를 구현한다.
   - 완료 기준: 네 기술의 직접 피해와 Poison Punch 독 적용 코드가 존재한다.
4. [완료] 템플릿 네 장의 `ScriptName`을 연결한다.
   - 완료 기준: 진행선 구조 테스트가 통과한다.
5. [완료] 서버를 빌드하고 런타임 스크립트 컴파일·우드랜드 전투를 검증한다.
   - 완료 기준: 관련 테스트가 통과하고 전체 회귀에서 새 실패가 없으며, 기존 실패는 구분해 기록한다.
6. [완료] 변경 diff를 수용 기준과 대조해 적대적으로 리뷰한다.
   - 완료 기준: 확인된 결함이 없거나 수정 후 재검증한다.
