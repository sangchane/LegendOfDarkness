## 목적과 범위
NEXT.md의 2026-09-30 UI 되돌림 목적 7개를 현재 화면 코드에서 다시 구현한다.
서버/프로토콜/게임 데이터는 그대로 사용한다. 시각 방향은 기존 4.51 회색·흙빛 재료,
밀도 7 / 모션 2 / 변화 2. 기존 Greybox 테마와 원작 캐릭터·아이템 아트를 재사용한다.
추가 요청: 원작에서 추출한 돌 에셋을 모바일 UI에 실제 적용한다. 창 테두리·제목 띠·
확정 버튼·선택 탭에 한정하고, 본문과 입력은 단색으로 남긴다. 기존 배치·터치 크기를 유지한다.
이 프로젝트의 논리 좌표는 1dp이므로 터치 48, 본문 16, 간격 8을 유지한다.

## 성공 조건
- 로그인: 자동 로그인 체크박스, 가로 두 영역(문장/폼), 회전해도 입력 보존.
- 만들기: 직업 5개를 스크롤 없이 표시, 머리/색/미리보기 공간 압축, 가로 3영역 간격 확보.
- 상점: 수량 0부터 선택, 여러 품목 0xF2로 전송, 전량 판매는 수량 채우기 후 확인,
  직업/성별/서클 필터, 첫 메뉴 복귀, 가로 중앙 넓은 창. 은행·일반 NPC 답변 경로 유지.
- 가방: 선택한 스택의 수량 입력 후 버리기. 정보창은 별도 레이어로 높이 변동 없음.
- 위 판: 말줄임 이름, 레벨, 만/억 골드. 모든 지도 표식은 한 칸 마름모, 색으로 구분.
- 없는 아이템 그림은 회색 타일. 기존 빈 장비 슬롯은 유지.

### 생성창 단색 텍스트·수동 회전 (2026-09-30, M)

로그인 화면은 확정 상태로 유지한다. 생성창의 제목 돌 띠·성별/직업 선택 타일을 없애고 로그인처럼 단색 바탕과 텍스트·선택 테두리로 표현한다. 마법사·원형 문양의 투명 PNG는 유지한다. 미리보기 좌우에 48dp 화살표를 두어 네 방향을 수동 선택하고, 꾸밈·화면 회전에도 방향을 유지한다. 자동 회전은 제거한다. 검증: 빌드, 7개 크기 레이아웃, 폰 2종·태블릿·가로 스크린샷, 실제 버튼 신호로 회전/방향 유지 확인.

검증 완료: .NET 빌드 오류/경고 0, `--resize-sequence --layout` 7개 크기 통과. 임시 Godot 스크립트로 실제 화살표 버튼 신호를 눌러 좌우·한 바퀴·성별 변경·2.5초 정지·가로 전환 뒤 방향 유지 확인(`CREATE_TURN_OK`). 폰 1080×2400/720×1600, 태블릿 1536×2048 및 640×360 가로 화면 확인. 미리보기 사각 테두리 제거, 가로 화살표 대비 보완. 구현 diff 리뷰 완료. 화면: `shots/stone-theme/create-flat-portrait.png`, `create-flat-landscape.png`, `create-flat/`.
