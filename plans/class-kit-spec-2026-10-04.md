# 직업 기술 꾸러미·대상 마법 조준 — SPEC (M, 2026-10-04)

## 요구(사용자)
- 무도가: 이형환위·단각·붕각·선풍각·달마신공·구양신공·다라밀공·쿠로토·반탄신공·금강불괴 **만** 스킬창(배치 목록)과 기술 막대에 보이고 배치된다.
- 다라밀공: 탭 = 고른 괴물, 없으면 가장 가까운 괴물에. 누른 채 끌면 그 방향 괴물을 조준(표시), 떼면 발사(모바일 롤). 가만히 0.5초 = 지금처럼 배치 목록.
- 자동 사냥은 막대에 놓인 기술·마법만 쓴다(회복 포함). 놓인 「적」 마법은 자동 사냥도 대상 괴물에 쓴다.
- 다른 직업도 같은 틀 — 표 한 줄씩 더하면 된다(특히 대상 마법).

## 근거(지금)
- 거르기 `LearnLadder.Roster`(Assail·beag ioc fein 만) · 막대 `AbilityBar`(길게 0.5초 = 배치 목록) · 대상 `SpellAim`(대상 마법은 고른 이, 없으면 나).
- 자동 사냥: 전투 기술은 막대에 놓인 것만(`PlacedSkills`), 회복은 **배운 마법 전부**, 공격 마법은 안 씀.
- 다라밀공 = 마법, TargetType 2(대상). **반탄신공은 서버에 없다**(기술·마법 템플릿·배움표 모두) — 표에는 넣어 두고, 서버에 들어오면 저절로 보인다.

## 만들 것
1. 알맹이 `Model/ClassKit` — 표 `assets/world/class-kit.txt`(`직업 · skill|spell · 이름 · 대상(적|나|-)`). 표에 줄이 없는 직업은 지금처럼 다 보인다.
   `Shows(직업, 마법?, 이름)`, `AimsAtEnemy(직업, 이름)`. 시험.
2. 화면: 막대·배치 목록에 표에 있는 것만(`GameScreen` 에서 배운 목록을 거른다, 목록의 「N레벨에 배움」 줄도 거른다).
3. 「적」 마법: 탭 → `WorldView.EnemyTarget()`(고른 이가 적대 괴물이면 그대로, 아니면 가장 가까운 적대 괴물을 골라 표시) → 0x0F. 없으면 「가까운 괴물이 없습니다」.
   끌기 → `WorldView.AimEnemy(끈 방향)`: 내 자리 + 끈 거리×3 에 가장 가까운 적대 괴물을 고름·표시. 떼면 발사, 단추 위로 돌아와 떼면 취소.
4. 자동 사냥: 회복은 막대에 놓인 마법에서만, 막대의 「적」 마법은 기술 다음·평타 앞에 대상 괴물에(`HuntAct.Cast`). 시험.
   표 다섯째 칸 `수동` 이면 자동 사냥은 쓰지 않는다 — **다라밀공은 수동**(쓰면 체력 1·마력 0 이라 자동 사냥이 쓰면 죽는다). 다른 직업 공격 마법은 비워 두면 자동 사냥이 쓴다.
5. (리뷰) 끌어 조준한 쪽에 괴물이 없으면 쏘지 않는다 · 식는 중이면 끌어 떼도 쏘지 않는다 · 막대가 줄어 그려지지 않는 자리에 놓였던 것은 빈 칸으로 돌아온다.
   남김: 입장 직후 직업(0x39)을 받기 전 잠깐은 표가 듣지 않는다.

## 안 할 것
반탄신공 서버 추가(따로 정할 일), 다른 직업 표 줄 채우기, 조준 사거리 표시 그림.

## 완료 기준
알맹이 시험(ClassKit·AutoHunt) 통과 · 앱 빌드 경고 0 · 무도가로 실제 앱: 막대에 표의 것만, 다라밀공 탭이 가까운 괴물에 나감(서버 기록/화면).
