# SPEC: 관리자 접속·게임 활동 통계 (L 변경)

## 배경·현재 상태
사용자는 10월 2일 이후 자기 아이폰(15 Pro, Monk5) 외의 웹·게임 접속을 알고 싶다.
nginx combined 로그는 웹 IP·UA·전송량을 담지만 HEAD도 포함한다. 게임은 NetworkServer.cs:124의 연결 IP와 GameServerHandlers.cs:3056의 환영 이름만 따로 남긴다.
기존 관리자 인증은 scripts/ops/ability-ops-service.py:371, 화면 탭은 docs/dashboard.js:17.

## 변경·데이터 흐름
- nginx 전용 JSON access 로그: 시각·request_id·IP·UA·쿼리를 뺀 경로·메서드·상태·전송량. 관리자 데이터는 공개 docs 밖 SQLite에 보관.
- 게임 서버의 공통 지점에서 성공 로그인/로그아웃/맵 입장 및 처리한 행동 요청을 JSONL로 기록. 요청과 성공 결과를 구분하며 전투·경험치·골드·레벨 변화는 서버 상태 차이로 기록. 봇 표시. 현재 저장 캐릭터의 허용된 레벨/경험치/금화/괴물별 누적 처치도 별도 표로 조회. 패킷 본문·비밀번호·채팅 내용은 제외.
- activity_store.py가 파일별 inode/offset으로 증가분을 SQLite에 수집. 날짜는 한국 시각, 보관 90일. 원시 로그도 회전·삭제. 실패 시 게임을 중단하지 않고 오류를 남김.
- GET /api/activity?from=YYYY-MM-DD&to=YYYY-MM-DD&player=...&bots=0|1: 기존 관리자 인증 필수. 날짜별 웹 방문·다운로드 요청/전송량·플레이어·행동 집계와 최근 200개 상세. 최대 90일, 쿼리 매개변수 바인딩.
- 웹 「접속·활동」 탭: 기간·캐릭터·봇 필터, 통계, 방문/IP·브라우저, 파일 전송, 게임 활동 상세, 마지막 수집/누락 상태. 모바일 표는 가로 스크롤 영역 내부에 둠. 외부 데이터는 textContent.
- 기존 10월 2일 이후 로그를 비공개 DB로 일회성 가져옴. 이전 게임 활동/기기·Wi-Fi 이름은 복구 불가. 다운로드 200/206 및 양의 전송량은 전송 기록이며 설치 완료/신원 확정과 구별.
