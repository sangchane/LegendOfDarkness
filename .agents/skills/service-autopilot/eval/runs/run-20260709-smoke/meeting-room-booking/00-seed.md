# Seed - 사내 회의실 웹 예약

- 원문: 사내 회의실 예약을 웹에서 하고 싶다. 지금은 화이트보드에 수기로 적는다.
- 서비스 유형: 내부 업무 SaaS / 웹 애플리케이션 / 공유 자원 예약
- 주 도메인: 사내 총무, 시설 관리, 회의실 예약 운영
- 인접 도메인: 조직/사용자 권한, 알림, 캘린더 연동, 공간 이용 분석
- 감지된 제약: 현재 운영은 화이트보드 수기 방식이며, 초기 문제는 중복 예약, 가시성 부족, 변경 이력 부재로 추정한다.
- 로드할 블라인드스팟 프로파일: P2 SaaS + 공통 10축 + STRIDE
- 자동 채택 기본값: 사내 단일 조직용, 직원 로그인 필수, PC/모바일 웹 지원, 관리자 승인 없는 즉시 예약을 MVP 기본값으로 둔다.
