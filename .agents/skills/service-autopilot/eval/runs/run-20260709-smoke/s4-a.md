# 서비스 기획 및 설계 문서: 라즈베리파이 IP 카메라 실시간 모니터링 서비스

## 1. 서비스 개요
본 서비스는 라즈베리파이(Raspberry Pi)를 활용하여 IP 카메라를 연동하고, 웹 또는 모바일 환경에서 실시간으로 영상을 모니터링하며 카메라를 제어할 수 있는 스마트 홈/오피스 보안 솔루션입니다. 사용자는 언제 어디서나 인터넷을 통해 모니터링 대상 구역의 상황을 파악하고, 필요시 방향 제어(PTZ) 및 알림 설정을 통해 능동적으로 대처할 수 있습니다.

## 2. 목표 및 기대효과
- **접근성 향상:** 웹 브라우저가 설치된 모든 기기에서 별도의 프로그램 설치 없이 실시간 모니터링 가능.
- **저비용 고효율:** 라즈베리파이라는 저렴한 싱글보드 컴퓨터를 활용하여 고가의 CCTV 시스템을 대체 가능.
- **확장성:** 향후 모션 인식, 객체 감지(AI) 등의 소프트웨어 모듈을 쉽게 추가할 수 있는 유연한 구조 제공.

## 3. 주요 기능
- **실시간 스트리밍:** 지연 시간을 최소화한 고화질 비디오 스트리밍 제공 (RTSP, WebRTC 또는 HLS 활용).
- **카메라 제어 (PTZ):** 연결된 카메라가 지원할 경우 팬(Pan), 틸트(Tilt), 줌(Zoom) 제어 기능 제공.
- **모션 감지 및 알림:** 영상 내 움직임 감지 시 스냅샷 캡처 후 사용자에게 푸시 알림 또는 이메일 전송.
- **녹화 및 저장:** 특정 시간대 예약 녹화 및 이벤트 발생 시 클라우드나 로컬 스토리지에 영상 자동 저장.
- **다중 사용자 및 권한 관리:** 관리자, 일반 사용자 등 권한에 따른 접근 제한 기능.

## 4. 시스템 아키텍처
- **Edge Device (라즈베리파이):**
  - IP 카메라와 네트워크 연결 또는 직접 카메라 모듈 연결.
  - 영상 스트리밍 서버(예: MotionEye, GStreamer, FFmpeg) 구동.
  - 센서 데이터 및 카메라 제어 명령 처리.
- **Backend Server (Node.js, Python FastAPI 등):**
  - 사용자 인증, 스트리밍 프록시, 기기 상태 관리, 알림 시스템(FCM, SMTP 등) 연동.
  - 데이터베이스 연동(사용자 정보, 이벤트 로그 등).
- **Frontend / Client (React, Vue.js 또는 모바일 앱):**
  - 스트리밍 영상 플레이어, 카메라 제어 패널, 설정 UI 제공.

## 5. 요구사항 (Requirements)
### H/W 요구사항
- **라즈베리파이:** Raspberry Pi 4 Model B (권장 4GB RAM 이상).
- **카메라:** 네트워크를 지원하는 IP 카메라 또는 라즈베리파이 공식 카메라 모듈.
- **기타:** 안정적인 전원 공급 장치, MicroSD 카드 (32GB 이상, 녹화용 별도 스토리지 권장).

### S/W 요구사항
- **OS:** Raspberry Pi OS (Debian 기반).
- **영상 처리:** OpenCV, FFmpeg, Motion.
- **통신 프로토콜:** RTSP, HTTP/HTTPS, WebRTC.

## 6. UI/UX 기획 요건
- **대시보드:** 여러 대의 카메라 영상을 그리드 뷰 형태로 동시 표출.
- **상세 뷰:** 특정 카메라 선택 시 전체화면 확대, PTZ 컨트롤러 조이스틱 형태 UI 제공, 녹화/스냅샷 버튼 배치.
- **설정 페이지:** 카메라 추가/삭제, 화질 설정, 모션 감지 감도 및 알림 연락처 설정.
- **반응형 웹 디자인:** 데스크톱, 태블릿, 스마트폰 등 다양한 해상도에 최적화.
