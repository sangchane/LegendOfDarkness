# PRD - 요양시설 낙상 감지 알림 서비스

## 배경

고령자 낙상은 빈번하고 예방 가능한 주요 안전 이슈다. 요양시설에서는 낙상 자체보다 발견 지연, 야간 미확인, 보호자 소통 누락, 사고기록 부실이 더 큰 운영 리스크가 된다. MVP는 "낙상 후보 감지와 대응 누락 방지"에 집중한다.

## 제품 목표

1. 낙상 후보 이벤트 발생 후 직원이 10초 이내 알림을 받도록 한다.
2. 직원이 실제 낙상 여부와 조치 결과를 2분 이내 기록하도록 유도한다.
3. 보호자에게 확정 낙상 또는 장기 미확인 이벤트를 30초 이내 전달한다.

## 사용자 스토리

- P1: 요양보호사로서 낙상 후보 이벤트를 즉시 받아 현장에 빠르게 이동하고 싶다.
- P1: 간호책임자로서 실제 낙상, 오탐, 미확인 이벤트를 추적해 교대 중 누락을 막고 싶다.
- P1: 보호자로서 실제 낙상 또는 확인 지연 상황만 신뢰성 있게 받고 싶다.
- P2: 시설장으로서 입소자별 위험도, 센서 상태, 대응 시간을 리포트로 보고 싶다.
- P2: 설치 운영자로서 배터리, 통신, 센서 장애를 원격 점검하고 싶다.

## 엣지 케이스

- Given 센서가 같은 입소자에게 30초 안에 5회 이벤트를 보낼 때, When 서버가 이벤트를 수신하면, Then 단일 낙상 후보로 병합하고 storm 지표를 기록한다.
- Given 직원 push가 실패할 때, When 5초 안에 수신 확인이 없으면, Then SMS fallback과 다음 당직자 escalaton을 실행한다.
- Given 중앙 서버 연결이 끊겼을 때, When 낙상 후보가 발생하면, Then 게이트웨이는 현장 알림을 울리고 복구 후 이벤트를 순서대로 전송한다.
- Given 보호자가 다른 입소자 알림 URL을 열 때, When 권한 검사를 수행하면, Then 403을 반환하고 접근 시도를 감사로그에 남긴다.

## UI 방향

- 직원 앱 첫 화면은 "미확인 낙상 후보" 목록과 큰 확인 버튼을 중심으로 한다.
- 보호자 화면은 사고 사실, 확인 시각, 시설 연락 경로만 보여주고 원시 센서값은 표시하지 않는다.
- 관리자 화면은 시설별 센서 상태, 평균 확인 시간, 오탐률, 미확인 이벤트를 표와 필터 중심으로 제공한다.

## 범위 밖

- 의료 진단, 치료 권고, 자동 119 신고는 MVP 범위가 아니다.
- 상시 영상 녹화와 영상 AI 판정은 MVP 범위가 아니다.
- 보험 청구, 전자의무기록 심층 연동은 MVP 범위가 아니다.

## 가정

- 입소자 또는 법정대리인의 서비스 이용 동의를 시설이 수집한다.
- 요양시설 내 Wi-Fi 또는 유선 게이트웨이를 설치할 수 있다.
- 직원은 근무 중 앱 또는 업무용 단말을 사용한다.
