# Seed - 요양시설 어르신 낙상 감지 알림 서비스

- 원문: "요양시설 어르신 낙상을 감지해 보호자와 직원에게 알리는 서비스를 만들고 싶다."
- 서비스 유형: 복합 서비스
  - IoT/엣지 디바이스: 착용형 또는 비착용형 센서로 낙상 후보 이벤트 감지
  - B2B SaaS: 시설, 직원, 보호자, 입소자, 알림 이력 관리
  - 모바일 알림: 직원 앱, 보호자 앱 또는 카카오/SMS/전화 연동
  - 보건·요양 운영 시스템: 사고 대응, 기록, 감사 추적
- 주 도메인: 장기요양시설 안전관리
- 인접 도메인: 의료기기/고령자 돌봄, 개인정보/영상정보, IoT 운영, 응급 알림
- 감지된 제약:
  - "요양시설"은 직원 교대, 야간 대응, 보호자 민원, 규제 기록 요구가 큼
  - "낙상 감지"는 오탐·미탐 비용이 모두 높음
  - 어르신 영상·위치·건강정보는 민감정보 또는 개인영상정보 이슈가 있음
- 로드할 블라인드스팟 프로파일: P1 IoT/엣지 디바이스, P2 B2B SaaS, P4 모바일, P3 관제/알람 운영 일부, STRIDE 전체
- 자동 채택 기본안:
  - MVP는 "침상/생활공간 낙상 후보 감지 -> 직원 1차 확인 -> 보호자 알림"으로 제한
  - 실시간 영상 AI 단독 판정은 MVP에서 제외하고, 프라이버시 침해가 낮은 센서 융합 우선
  - 법적 의료 판단이 아니라 안전 알림·대응 기록 서비스로 포지셔닝
