## 제품 진단 (ecc:product-lens Mode 1 — 7문, PRODUCT-BRIEF 대신 여기에 흡수)
1. 누구를 위해: 국내 노인요양시설(장기요양기관)의 **야간 근무 요양보호사·간호(조무)사**(1차 사용자), 시설장(구매 결정), 보호자(통보 수신). "개발자"나 "노인" 일반이 아니다.
2. 고통: 노인요양시설은 65세+ 낙상 최다 발생 장소(2024년 523건, 소비자원 CISS — 01-recon). 야간에 1명이 다수 입소자를 순회하므로 **무목격 낙상 → 바닥 방치**가 핵심 고통. 오늘은 순회 + 사후 CCTV 확인으로 대응.
3. 왜 지금: 2023.6.22 CCTV 설치 의무화로 시설에 네트워크·영상 관리 프로세스가 생김 · 2025 배치기준 2.1:1 강화로 인건비 압박 · mmWave/온디바이스 비전 상용화(Vayyar·Kepler·Milesight, 01-recon).
4. 10-star: 전 공간 비접촉 감지 + 낙상 위험 예측 + 너스콜·기록시스템 연동 + 보호자 실시간 공유 + 공단 평가 자동 보고.
5. MVP: 침실·복도 센서 → 감지 → 직원 앱·관제 알림 → 현장 확인·조치 기록 → **확인된 낙상만** 보호자 통보 → 낙상 보고서.
6. Anti-goal: 낙상 예측·활력징후(의료기기 경계), 요양병원, EMR/공단 시스템 연동, 법정 CCTV 대체, 119 자동 신고.
7. 지표: 감지→직원 단말 표시 지연, 바닥 방치 시간, 미감지율(민감도), 오탐/센서/주, 보호자 통보 도달 시간 (03 SC로 구체화).
→ 진단 결론: go. 근거는 위 2·3. 리스크 상위 = 감지 수단(Q1)·의료기기 경계(Q2).
