# 채점 루브릭 — 하네스 vs 베이스라인

동일 시드에 대한 두 출력(하네스 적용 / 미적용)을 비교 채점한다.
채점자는 어느 쪽이 하네스 출력인지 모르는 블라인드 상태로 진행한다.

## 항목 (각 0~5점, 셀 수 있는 근거로 채점)

| # | 항목 | 채점 방법 |
|---|---|---|
| R1 | 근거 인용률 | 사실 주장 중 URL+확인일이 붙은 비율. 80%↑=5, 50%=3, 0%=0 |
| R2 | 도메인 표준 커버리지 | 시드별 필수 표준 체크리스트(seeds.md에 정의) 대비 언급·반영 비율 |
| R3 | 질문 효율 | 질문 5개 이하이면서 위험 가정(보안·규제·비가역 결정)을 질문 없이 확정하지 않았는가 |
| R4 | 결정 추적성 | 기술·범위 선택 중 "이유 + 버린 대안"이 명시된 비율 |
| R5 | 형용사 잔존율 | 검증 기준 없는 질적 표현 개수. 0개=5, 1~2개=3, 5개↑=0 |
| R6 | 실행 가능성 | 백로그 항목 중 검증 가능한 완료 기준을 가진 비율 |

## 판정 규칙

- 시드당 최소 2회 반복 실행 후 평균 (실행 간 편차 흡수).
- 총점 우위 + 어떤 개별 항목도 1점 초과 후퇴 없음 → 하네스(또는 도전자) 승.
- 총점 차이가 시드 평균 2점 이내면 무승부로 보고 사람 리뷰로 판정.
- 한계 명시: 기획 품질은 완전히 객관화되지 않는다. 이 루브릭의 목표는 완벽한 증명이 아니라 "의문이 남지 않을 수준의 반복 가능한 비교"이고, 최종 판단에는 항상 사람 리뷰가 들어간다.
