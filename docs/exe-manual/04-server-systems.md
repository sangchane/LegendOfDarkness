# 5.99 서버 실행 파일 매뉴얼 4 — 시스템 (스크립트 엔진·아이템·NPC·사회·저장·운영)

`~/Downloads/5.99 서버팩/Novaonline.exe`(32비트 PE, md5 `d36015ac…aa71`)를 역어셈블해 읽은 것이다.
전투 공식·능력치·장착 규칙·혼수처럼 이미 정리된 것은 다시 쓰지 않고 링크한다 —
[역어셈블 요약](../disassembly.md) · [findings.json](../../data/disassembly/findings.json) ·
[서버팩 자료 규칙](../server-pack-data.md) · [5.99 팩 요약](../server-packs/5.99-server.md) · [서버 말 한국어](../server-messages-ko.md).

- **읽는 법:** 주소는 `.text` 가상 주소(16진수). 역어셈블(맥 objdump)은 **오프셋을 10진수로** 찍는다 — `[ecx + 224]` = `+0xE0`.
  문자열은 `push 상수`의 주소를 파일 위치로 바꿔 CP949 로 읽었다(.rdata `0x481000`, .data `0x483000`).
- **근거 발췌:** `data/disassembly/excerpts/manual-server-sys-*.asm` (아래 표마다 이름을 적었다).
- **이 서버는 eAthena 계열이다.** 빌드 경로 `C:\NovaOnline - F 5.99\novaonlineSRC - F\eA\script.c`(`0x48e86c`),
  `db_put`·`ers_alloc` 오류문(`0x4917e8`~)이 그대로 남아 있다. 스크립트 엔진은 eA `script.c` 를 한국어 게임에 붙인 것이다.
- **"모름"은 모른다고 적었다.** 표의 `확인 못 함` 은 함수는 찾았지만 뜻을 코드로 못 가렸거나, 코드를 못 찾은 것이다.

## 2. 접속(로그인) 흐름

로비 `0x412c8a`(opcode 0x00·0x10·0x57·0x62) → 로그인 `0x413b93` → 게임 `0x417e4f`(3장 opcode 표).

| 단계 | 서버가 보는 것 | 말 |
|---|---|---|
| 버전 | 0x00 로 받은 버전을 콘솔에 찍는다 | ` [!] 어둠의 전설 v%d.%d 버전 접속 감지!` (`0x413189`) |
| IP 차단 | `BanList.txt` 의 `a . b . c . d` 줄 | `당신은 차단된 아이피입니다.` |
| 계정 만들기(0x02) | 이름 꼴·중복 | `계정을 바르게…` · `이미 등록된 계정입니다.` |
| 로그인(0x03) | 없는 계정·비밀번호·`아이디제재`=1·**관리자모드**(전역 `0x4ad0c8`=1 이면 막음)·이미 접속 | `없는 계정 입니다.` · `비밀번호가 틀렸 습니다.` · `부정행위로 인한 로그인 제재…` · `현재 유저접속이 불가능한 상태입니다.[개발중]` · `이미 접속되어있는 계정 입니다.` |
| 비밀번호 바꾸기(0x26) | 2차 비밀번호 | `2차 비밀번호가 일치하지 않습니다.` · `변경완료` |
| 들어옴(게임 0x10) | `log/YYYYMMDD.txt` 에 한 줄(날짜·요일·IP·아이디·운영진/부운영진/일반유저) → 로그인 스크립트 → 낀 장비마다 `장착펄숫` 다시 실행 | `0x46c216` |

## 3. 스크립트 엔진

### 3.1 파일 문법

```
0,0,0,0,0,0,0<탭>스크립트이름<탭>{
    set @myid, get_myid();
    if(get_level(@myid) < 81){ message 3, "아직 입장할수 없습니다."; end; }
    warp "드라큐라백작의성동1", 2, 14;
}
```

- 한 덩어리 = `머리<탭>이름<탭>{ … }`. 머리 7칸은 팩 330개 모두 `0`(읽는 꼴은 `%d,%d,%d,%d,%d,%[^,],…` `0x486ce4`) — 뜻 확인 못 함.
  **이름이 곧 연결 고리**다: NPC 배치·아이템 펄숫·워프·`callfunc` 가 모두 이름으로 부른다. 같은 이름 두 번이면 `이미 추가된 펄숫 입니다` 오류.
- 제어문은 eA 그대로이고, 컴파일 때 `goto` 로 풀린다: `if/else`(`__IF%x_%x`) · `switch/case/default/break`(`$@__SW%x_VAL` — 이 임시 변수가 `map_reg.txt` 에 새어 저장된다) ·
  `for` · `while` · `do…while` · `continue` · `function`/`callsub`/`return` · `goto 라벨;` + `라벨:` (`0x48e160`~`0x48e5a4`).
- 오류는 콘솔에 `Script Error on %s line %d`(`0x48e5b0`)와 줄 번호를 찍는다.

## 5. NPC 상점·은행·수리

### 5.1 상점 목록은 어디서 정해지나

```
물건사기<탭>체력포션<탭>{          ← 갈래(물건사기/물건팔기) + 상점 이름

```

- `db/npc/Shop.txt`(매니페스트 `shop:`)를 서버 시작 때 한 번 읽는다(`0x40d6ef` → 낱말 `물건사기` `물건팔기` `추가`, 최대 255개 `0x486ee4`). **시각·요일·재고 칸은 없다.**
- NPC 와 상점을 잇는 것은 **스크립트**다: `shop 0, "체력포션", "어느 물약을…"` (0 사기 · 1 팔기, `0x440aad` 가 이름으로 찾는다 `0x40f12f`, 없으면 `buildin_shop: invalid shop name`).

  5.99 팩은 하지 않는다. 시간 관련 엔진 재료는 `__TIME_SCRIPT__`(1초), `localtime`, `time`, `$` 서버 변수뿐이다.
