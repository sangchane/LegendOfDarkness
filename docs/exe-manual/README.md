## 한눈에 — 모바일로 옮길 때 먼저 볼 것

- **평타는 늘 맞는다**(명중·회피 없음) · 피해 = 공격력 ± 난수 10 → 치명타 (값+1)% ×2 → AC `피해×(1 + AC×0.01)` (03 4절)
- **등 뒤 ×2 는 원작 서버에서 실제로 일어나지 않는다** — 배수를 넘기는 길을 아무도 안 부른다(03 4.2). 우리는 사용자 결정으로 넣었다
- 속성 상성표 없음 — 공격 쪽에 속성이 있으면 ×1.3 (03)
- 그룹 경험치는 **나누지 않고 전원이 다 받는다** · 죽으면 경험치 1% (03)
- 클라이언트는 내 걸음을 **서버 응답 전에** 움직이고 되돌리지 않는다 · 평타 100ms 간격 (01·02)
- 상점 목록은 서버 시작 때 고정 — **시간 순환 상점은 엔진에 없다**, 스크립트 시간 훅으로만 만들 수 있다 (04 5절)
- 저장 15초마다 · 가방 60칸 · 겹치기 44개 · 그룹 12명 (04)
- **노바 서버의 뒷문 채팅 명령(04 0절 9번)은 절대 옮기지 않는다**

각 장 끝 「모르는 것」에 확인 못 한 것을 모아 두었다. 새로 알게 되면 주소와 함께 그 장과 `findings.json` 에 더한다.
