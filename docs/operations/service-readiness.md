# 서비스 준비도 게이트

## 현재 단계

**분석·로컬 실행 검증 — 공개 테스트 전.** 서버 기동과 프로토콜 분석 자료는 있지만, 공개 서비스에 필요한 인증 강화, 관측성, 복구 리허설, 배포·롤백 자동화가 완료됐다는 근거는 없다.

## 판정 방식

각 게이트에는 `상태`, `책임 역할`, `마지막 검증일`, `판정 근거`를 남긴다. 체크 표시만으로 완료하지 않으며, 테스트 결과·빌드 ID·로그 검색·복원 기록처럼 다른 사람이 재현할 수 있는 근거가 있어야 한다.

| 단계 | 허용 범위 | 진입 조건 | 현재 판정 |
|---|---|---|---|
| L0 분석 | 코드·문서 조사 | 원본 보존, 비밀 미노출 | 확인됨 |
| L1 로컬 검증 | 개발자 PC의 제한된 실행 | 안전한 기동·종료 절차, 테스트 데이터 | 부분 |
| L2 팀 개발 | 내부 계정과 공유 환경 | CI, 권한 분리, 중앙 로그, 자동 백업 | 미구현 |
| L3 비공개 테스트 | 초대된 외부 사용자 | TLS, 안전한 인증, 개인정보 고지, 장애 당번, 복원 리허설 | 미구현 |
| L4 공개 테스트 | 불특정 사용자 | 용량 시험, 남용 방지, 고객 대응, 배포·롤백 훈련 | 미구현 |
| L5 정식 운영 | 유료화 또는 지속 서비스 | 승인된 SLO/RPO/RTO, 보안 검토, 법무·스토어·결제 준비 | 미구현 |

## 핵심 게이트

| 영역 | 통과 조건 | 현재 구현 상태 | 판정 근거 |
|---|---|---|---|
| 사용자 여정 | 가입→로그인→월드 진입→이동→전투→재접속 E2E | 미구현 | 프로토콜 분석과 모바일 검증 결과 연결 필요 |
| 인증·권한 | 비밀번호 해시, TLS, 세션 만료·폐기, 관리자 RBAC | 미구현 | [보안 유지보수](security-maintenance.md) |
| 데이터 | 원자적 저장, 마이그레이션·롤백, 무결성 검증 | 미구현 | JSON 파일 저장 위험 검토 필요 |
| 관측성 | 로그·메트릭·트레이스의 공통 상관관계 ID와 경보 | 미구현 | 신호별 수집·보존 결정 필요 |
| 복구 | 승인된 RPO/RTO 안에서 격리 복원 성공 | 미구현 | [백업·복구](backup-restore.md) |
| 릴리스 | 동일 산출물 승격, 출처 증명, 호환성·롤백 검증 | 미구현 | [릴리스·롤백](release-rollback.md) |
| 장애 대응 | 당번·심각도·연락망·훈련 기록 | 미구현 | [장애 대응](incident-response.md) |
| 모바일 운영 | 스토어 정책, 최소 지원 OS, 강제/선택 업데이트 정책 | 결정 필요 | 제품 책임자 승인 필요 |
| 고객·법무 | 약관, 개인정보, 신고/제재, 탈퇴·삭제 | 결정 필요 | 서비스 국가·연령·수익모델 선행 |

## 운영 금지 조건

다음 중 하나라도 해당하면 공개 테스트나 정식 운영으로 승격하지 않는다.

- 평문 또는 복호화 가능한 형태로 사용자 비밀번호를 저장한다.
- 인터넷 구간에 TLS 없이 인증·게임 세션을 노출한다.
- 관리자 기능에 인증, 최소 권한, 독립 보존·무결성 검증이 가능한 감사 로그가 없다.
- 운영 자격 증명으로 수정·삭제할 수 없는 복구 지점, 성공한 복원 리허설, 삭제 내성 시험 중 하나라도 없다.
- 배포 산출물의 커밋·의존성·설정 버전을 추적할 수 없다.
- 치명 장애의 담당자와 서비스 중지 기준이 없다.
- 데이터 손실·계정 탈취 가능성이 있는데 경보와 대응 절차가 없다.

## 첫 운영 지표 후보

수치는 아직 확정하지 않는다. 먼저 계측한 뒤 제품 영향과 운영 비용을 보고 승인한다.

- 로그인 성공률과 p95 응답 시간
- 로그인 성공 후 월드 진입 성공률
- 비정상 연결 종료율과 재접속 성공률
- 서버 틱 지연 및 명령 처리 지연
- 저장 실패·데이터 무결성 오류 건수
- 배포 빈도, 변경 실패율, 복구 시간

각 지표는 `정의`, `분모/분자`, `제외 조건`, `수집 위치`, `경보 임계값`, `책임 역할`을 함께 적는다. SLO 값과 오류 예산은 **결정 필요**다.
