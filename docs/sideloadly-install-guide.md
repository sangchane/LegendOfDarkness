# 멀리 있는 사람 아이폰에 앱 넣기 — Sideloadly 작업지침

> 맥에 케이블을 꽂을 수 없는 사람이 **자기 컴퓨터와 자기 애플 계정**으로 앱을 넣는 방법이다.
> 1부는 보내는 사람(우리), 2부는 받는 사람(컴퓨터를 잘 못 다뤄도 따라 할 수 있게)이 본다.
> 2부만 잘라 카카오톡으로 보내도 된다.

---

## 1부 — 보내는 사람(우리)이 할 일

1. **받는 사람에게는 주소와 손님 비밀번호를 보낸다: https://lodgame.duckdns.org/?view=download** — 내려받기 단추와 그림이 들어간
   설치 방법(아래 2부와 같은 내용)이 대시보드 「앱 내려받기」 탭에 있다. 손님 비밀번호로 로그인해야 열린다(2026-10-09). 원본 `docs/index.html`·`docs/download.js`.
2. 페이지의 앱 파일은 **`scripts/ops/ios-build.sh install` 이 내 폰에 넣는 데 성공하면 저절로 최신판으로 바뀐다.**
   폰 없이 올리려면 `scripts/ops/ios-build.sh build && scripts/ops/ios-build.sh release`.
   페이지 글·그림을 고쳤으면 `LOD_CLOUD_IP=161.33.43.117 scripts/ops/cloud-dashboard.sh deploy`(게임 서버는 안 끊긴다).
3. **윈도우 PC판**도 같은 페이지 「윈도우 PC」 탭(주소 끝 `#pc`)에 있다 — 압축만 풀고 실행, 서명·7일 제한 없음.
   만들고 올리기: `scripts/ops/windows-build.sh release`(맥에서 그대로 만든다).
4. 가능하면 **처음 한 번은 전화를 하면서** 같이 한다(10~20분).

⚠️ `mobile/client/login.cfg`(맥 시험용 자동 로그인)는 내보내기에서 뺀다(`export_presets.cfg` exclude_filter). 두 빌드 스크립트가 실렸는지 한 번 더 보고 멈춘다.

알아 둘 것
- 무료 애플 계정으로 넣은 앱은 **7일 뒤 열리지 않는다**. 그때 같은 방법으로 다시 넣으면 된다(캐릭터는 서버에 있어 그대로다).
- 받는 사람 계정 한 개로 이런 앱은 3개까지만 넣을 수 있다.

---

## 2부 — 받는 사람이 할 일

### 준비물
- 윈도우 컴퓨터(또는 맥) 한 대
- 아이폰과 **충전 케이블**(사진을 옮길 수 있는 케이블. 충전만 되는 싸구려 줄은 안 된다)
- 애플 계정 아이디·비밀번호, 그리고 인증 번호를 받을 수 있는 아이폰
  - 걱정되면 이 일에만 쓸 **새 애플 계정**을 하나 만들어 써도 된다.
- 받은 앱 파일 `LodClient.ipa` — **바탕화면**에 저장해 둔다.

### ① 아이튠즈 깔기 (처음 한 번만)
1. 인터넷 창에 `apple.com/kr/itunes` 를 친다.
2. **「Windows용 iTunes 다운로드」** 아래의 **「다른 버전을 찾고 있습니까? → Windows」** 쪽에서 받는다.
   - ⚠️ **마이크로소프트 스토어(파란 가방 아이콘)에서 받은 아이튠즈는 안 된다.** 이미 그걸로 깔았다면 지우고 다시 깐다.
3. 다 깔리면 컴퓨터를 한 번 껐다 켠다.

> 맥을 쓰는 사람은 ①을 건너뛴다.

### ② Sideloadly 깔기 (처음 한 번만)
1. 인터넷 창에 `sideloadly.io` 를 친다. **꼭 이 주소에서만** 받는다(비슷한 이름의 다른 사이트는 받지 않는다).
2. 「Download」에서 윈도우(또는 맥)용을 받아 설치한다. 묻는 것은 모두 「다음」「예」를 누르면 된다.

### ③ 아이폰을 컴퓨터에 연결 (처음 한 번만)
1. 케이블로 아이폰을 컴퓨터에 꽂는다.
2. 아이폰 화면에 **「이 컴퓨터를 신뢰하겠습니까?」** 가 뜨면 **「신뢰」** → 아이폰 암호를 넣는다.

### ④ 앱 넣기 (7일마다 이것부터 다시)
1. Sideloadly 를 연다.
2. 맨 위 칸에 **내 아이폰 이름**이 보이는지 본다. 안 보이면 케이블을 뺐다 다시 꽂는다.
3. 바탕화면의 `LodClient.ipa` 를 Sideloadly 창 왼쪽의 **IPA 그림(네모)** 위로 끌어다 놓는다.
4. **Apple account** 칸에 애플 계정 이메일을 넣는다.
5. **「Start」** 를 누른다.
6. 비밀번호를 물으면 애플 계정 비밀번호를 넣는다.
7. 아이폰(또는 다른 애플 기기)에 뜬 **여섯 자리 인증 번호**를 묻는 창이 나오면 그 번호를 넣는다.
8. 아래쪽 글자가 쭉 올라가다가 **「Done.」** 이 나오면 끝이다(1~3분).

### ⑤ 아이폰에서 「믿기」 (처음 한 번, 그리고 다시 막히면)
1. 아이폰 **설정 → 일반 → VPN 및 기기 관리** 로 간다.
2. 「개발자 앱」 아래에 **내 애플 계정 이메일**이 보이면 누른다.
3. **「(이메일) 신뢰」** → 다시 **「신뢰」**.

### ⑥ 개발자 모드 켜기 (처음 한 번만)
앱을 눌렀을 때 「개발자 모드가 필요하다」고 나오면:
1. **설정 → 개인정보 보호 및 보안** → 맨 아래 **「개발자 모드」** → 켠다.
2. 아이폰이 다시 켜지면 화면에 뜬 **「켜기」** 를 누르고 아이폰 암호를 넣는다.
3. 이제 홈 화면의 앱을 누르면 열린다.

### 7일 뒤 앱이 안 열리면
④ 부터 다시 한다(①②③⑥ 은 다시 할 필요 없다). 새 파일을 받았으면 그 파일로 한다.

## 막힐 때

| 이런 말이 나오면 | 이렇게 |
|---|---|
| Sideloadly 맨 위에 아이폰이 안 보인다 | 케이블을 다른 구멍에 꽂기 · 아이폰 잠금 풀기 · 「신뢰」 다시 누르기 · 아이튠즈가 스토어판이면 지우고 ①부터 |
| 「iTunes not installed」 비슷한 말 | ①을 다시 한다(스토어판이 아닌 것으로) |
| 비밀번호를 넣었는데 틀렸다고 한다 | 애플 계정 웹사이트에서 로그인이 되는지 먼저 확인 |
| 「maximum number of apps」 비슷한 말 | 예전에 이렇게 넣은 앱을 아이폰에서 하나 지우고 ④ 다시 |
| 앱을 누르니 「신뢰하지 않는 개발자」 | ⑤ |
| 앱을 누르니 바로 꺼진다 / 안 열린다 | 7일이 지났을 수 있다 → ④ 다시 |
| 그래도 안 되면 | Sideloadly 창 아래쪽 글자를 **사진 찍어** 보낸 사람에게 보낸다 |
