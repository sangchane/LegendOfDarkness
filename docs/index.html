                  관리자 전용

                  접속·활동 기록

                  웹 방문과 앱 전송, 캐릭터 접속과 게임 활동을 날짜별로 봅니다.

                  관리자 로그인 후 조회할 수 있습니다.

                  한국 시각 · 90일 보관 · 앱 통계 날짜는 서버 수신일 기준 · IP/브라우저는 접속 환경이며 사람·기기 신원을 확정하지 않습니다. 다운로드는 GET 파일 전송(부분 전송 포함), 설치 완료 여부는 알 수 없습니다. 방문에는 자동 수집기가 포함됩니다.

                  날짜별 통계

                  웹 방문자 · 접속 환경

                  앱 다운로드 전송

                  게임 캐릭터 통계

                  처리한 기술·마법 등 요청 수는 성공 횟수와 다릅니다. 접속 시간은 종료된 세션 기준, 경험치·금화는 기록 구간의 순변화입니다.

                  동시 접속 · 재방문

                  앱 기기 · 운영체제 · 버전

                  앱이 보고한 값입니다. 설치 식별자는 임의로 만들며 재설치하면 달라질 수 있습니다. 기기 신원이나 Wi-Fi 이름을 증명하지 않습니다.

                  접속 실패 · 앱 오류

                  비정상 종료(unclean_exit)는 강제 종료·운영체제 종료·크래시를 구분하지 못합니다. 앱 기록과 이전 실행의 진단(previous_run_exception)은 다음 로그인 성공 때 전송될 수 있으며, 인증 전 진단은 로그인한 계정에서 발생했는지 확정하지 않습니다. 서버 시각은 수신 기준이고 앱 보고 시각은 앱 시계 기준입니다. 이전 종료 진단의 시각은 발견한 시각입니다. 사유와 예외 종류만 수집하며 입력 내용·오류 메시지·대화는 수집하지 않습니다.

                  화면 이용 · 버튼 · 이탈

                  화면·버튼은 코드로 표시하며 입력한 글은 기록하지 않습니다. 앱이 서버에 보낸 표본의 집계로, 전송하지 못한 마지막 구간은 빠질 수 있습니다.

                  아이템 · 금화 · 경험치 원장

                  실제 상태 변화 기준입니다. 이동은 획득·소비와 따로 보며, 보정(reconcile)은 관측 사이 변화입니다. 사유는 서버 코드 경로입니다. 기존 순변화와 원장을 더하면 중복됩니다.

                  캐릭터에 남아 있는 누적 기록

                  기간 필터와 별개로 현재 저장된 레벨·경험치·금화·처치 기록입니다. 처치 횟수는 게임 서버가 귀속시킨 카운터이며 이전 날짜별 내역은 알 수 없습니다. 서버 저장 주기만큼 늦을 수 있습니다.

                  게임 행동 통계

                  최근 게임 활동

                  상세 표는 각각 최근 200행입니다. 더 이전 기록은 날짜/캐릭터로 좁혀 조회하세요. 도입 이전 활동·접속 시간은 복구할 수 없습니다. 요청은 60초마다 묶어 기록하며 강제 종료 직전 구간은 빠질 수 있습니다.
