## 번호가 뜻하는 것
- 우리 원작 곡은 `sources/wren11/Dark-Ages-Private-Server/database/assets/MusicFiles/<번호>.mus`(속은 MP3) 64곡,
  앱에는 `mobile/client/assets/music/<번호>.ogg` 로 들어가 있다(`scripts/gen/client/build-client-music.py`).
- 맵이 트는 곡은 서버 맵 정의 `database/server/areas/*.json` 의 `Music` 칸 − 128 이다(노비스마을 150 → 22번).
- 재생목록의 「어둠의전설 BGM - 0NN」 은 **우리 파일 번호와 같다** — 21곡 모두 길이가 1초 안으로 맞고,
  파일 이름표(ID3)도 맞는다(44 "FORTE FOREST" = 「044 포테의숲」, 45 "woodlands" = 「045 우드랜드」).

## 재생목록과 지금 서버가 어긋나는 곳
1. 포테의숲 — 서버는 17번, 재생목록·파일 이름표는 44번(FORTE FOREST). 44번은 지금 놀이동산이 튼다.
2. 마운틴메리 — 서버는 29번(크리스마스마을과 같은 곡), 재생목록은 30번. 30번은 지금 루어스마을이 튼다.
3. 로톤마을 — 서버는 27번(죽음의마을과 같은 곡), 재생목록은 64번.
4. 구버전 기준이면 루어스성 18번 · 피에트·마인 12번 · 수오미 11번 — 지금은 33번 · 32번·6번 · 13번.
