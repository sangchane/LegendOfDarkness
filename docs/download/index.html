막힐 때

Sideloadly 맨 위에 아이폰이 안 보여요케이블을 다른 구멍에 꽂기 · 아이폰 잠금 풀기 · 3번 「신뢰」 다시 · 아이튠즈가 스토어판이면 지우고 1번부터
「iTunes」「iCloud」가 없다는 말이 나와요1번을 다시(스토어판이 아닌 것으로). iCloud 를 요구하면 sideloadly.io 첫 화면에 있는 iCloud 링크로 깝니다.
비밀번호가 틀렸다고 해요애플 계정 홈페이지(account.apple.com)에서 로그인이 되는지 먼저 확인하세요.
「maximum number of apps」 비슷한 말이 나와요예전에 이렇게 넣은 앱을 아이폰에서 하나 지우고 4번을 다시 합니다.
앱을 누르니 「신뢰하지 않는 개발자」래요5번을 합니다.
앱을 누르면 바로 꺼져요 / 안 열려요7일이 지났을 수 있습니다 → 0번과 4번을 다시.
애플 계정을 넣기가 걱정돼요이 일에만 쓸 새 애플 계정을 하나 만들어 써도 됩니다.

그래도 안 되면 Sideloadly 창 아래쪽 글자를 사진으로 찍어 알려 주신 분께 보내 주세요.
