막힐 때

Sideloadly 맨 위에 아이폰이 안 보여요

케이블을 다른 구멍에 꽂고, 아이폰 잠금을 풀고, 3번 「신뢰」를 다시 하세요. 아이튠즈가 스토어판이면 지우고 1번부터.

「iTunes」「iCloud」가 없다고 나와요

1번을 다시 하세요(스토어판이 아닌 것으로). iCloud 를 요구하면 sideloadly.io 첫 화면의 iCloud 링크로 깝니다.

「maximum number of apps」 비슷한 말이 나와요

예전에 이렇게 넣은 앱을 아이폰에서 하나 지우고 4번을 다시 하세요.

앱을 누르면 「신뢰하지 않는 개발자」

5번을 하세요.

앱이 바로 꺼지거나 안 열려요

7일이 지났을 수 있습니다. 파일을 다시 받아 4번을 하세요.
