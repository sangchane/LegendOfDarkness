## 3. 사용자 기억 예시와 맞는지
- 「수오미 = 일단검수·팔루텐수」: **근거 없음.** 혼든 수오미 무기상 가이(`수오미마을_shop.txt:64`)는 변형 없이 월단검·광단검만, 방어구상 아돌(`:13`)은 기본 `팔루텐`(`:15`)만 판다. `일단검수`는 어느 상점에도 없고(기본 `일단검`은 `아벨마을_shop.txt:85`), `팔루텐수`는 운디네 오딘(`운디네마을_shop.txt:48`)에만 있다.
- 「동서남북 우드랜드 = 밀레스팔루텐 수·토·풍·화」: **근거 없음.** 혼든에는 우드랜드 상인이 없다(`scripts/gen/items/build-town-gear-shops.py` 머리말도 같은 말). 밀레스팔루텐 수·토·풍·화는 밀레스 상점(케빈·듀크)에 동시 판매로만 있다. 노바 팩 `db/npc/woodland.txt` 는 0줄.
- 다만 「마을마다 속성이 정해져 있다」는 기억은 운디네 수 / 아벨 토 / 피에트 풍 / 루어스 화로 뒷받침된다.

## 4. 순환(시간) 단서 — 못 찾음
- 5.99 서버팩(`~/Downloads/5.99 서버팩/db`, `npc/Shop.txt`): 수토풍화 변형 이름 **0건**(CP949 로 읽어 전부 검사). 상점은 정적 `추가` 목록뿐.
- 노바온라인(`data/server-packs/novaonline/db`): 변형은 `item/armor/armor.txt`(예 `:1863` 팔루텐수 · `:11852` 수오미팔루텐수)·`item/weapon/dagger.txt` 정의에만 있고, `npc/` `script/` 어디에도 판매·드랍 줄 없음(`admin_shop.txt` 는 기본형만).
- 스크립트 언어에는 **시계가 있다**: 5.99 `db/script/script.txt` 머리 주석 `localtime(1~7)`(년·월·일·시·분·초·요일, `:610` 부근 「타임스크립트」), 혼든 `db/script/script.txt:2898-2922`(`localtime(4)==20&&localtime(5)==0` 로 이벤트 시작). 하지만 **상점 목록을 바꾸는 명령은 어느 팩에도 없다**(상점 파일은 정적 `물건사기/추가`뿐, 시간·요일·랜덤 문구는 이벤트·게시판·`랜덤캐쉬주머니`뿐).
- 원작 기억 문서(`docs/darkages-cafe/`, `docs/original-items/`)에 순환·속성 상점 언급 없음(`docs/original-items/*` 는 변형 아이템 도감 항목뿐).
- 실행 파일 `Novaonline.exe`(objdump) 속 순환 단서는 이번에 열지 않았다 — 필요하면 별도 조사.
