# 서버팩 자료 — 방법과 공통 규칙

- 기준일: 2026-09-12
- 팩별 내용은 따로 있다: **[5.99 서버팩](server-packs/5.99-server.md)** · **[혼든커뮤니티팩2](server-packs/honden-community.md)**
- 단일 출처: `data/server-packs/extracted/<팩>/*.json` (커밋됨) · 노트와 그래프는 거기서 나므로 커밋하지 않는다

원작 자료(`docs/game-data.md`)와는 **다른 것**이다. 그쪽은 원작이 배포한 표이고,
이쪽은 남이 원작을 고쳐 돌리던 서버의 데이터베이스다. 섞지 않는다.

## 만드는 순서

```
python3 scripts/build-server-pack-data.py        # db/ → JSON
python3 scripts/build-server-pack-quests.py      # 스크립트 → 퀘스트·이벤트
python3 scripts/build-server-pack-vault.py       # JSON → Obsidian (팩마다 따로)
python3 scripts/build-server-pack-graph.py       # JSON → 지식 그래프
python3 scripts/extract-script-commands.py <서버.exe> <팩>   # 실행파일 → 명령표
python3 scripts/classify-script-names.py         # 스크립트가 부르는 이름 갈래짓기
.venv/bin/python scripts/disasm-script-commands.py <서버.exe> <팩>  # 기계어 → 증거
```

마지막 것만 `capstone`·`pefile` 이 필요하다. 시스템 파이썬에는 넣지 않는다(PEP 668):

```
python3 -m venv .venv && .venv/bin/pip install capstone pefile
```

## 팩마다 따로 두는 이유

| 갈래 | 5.99 | 혼든 | 겹침 | 5.99에만 | 혼든에만 |
|---|---|---|---|---|---|
| 아이템 | 989 | 3,138 | 449 | 540 | 2,689 |
| 괴물 | 242 | 821 | **35** | 207 | 786 |
| 맵 | 804 | 1,711 | 264 | 540 | 1,447 |
| 기술 | 82 | 184 | 58 | 24 | 126 |
| 마법 | 71 | 167 | 48 | 23 | 119 |

괴물이 242종과 821종인데 이름이 겹치는 것이 **35종뿐**이다. 같은 계열이라고 묶으면 어느 쪽
수치인지 알 수 없게 된다. 그래서 JSON·vault·그래프를 팩마다 하나씩 만든다.

엔진까지 다르다: `Novaonline.exe` 401개 명령, `Yuki.exe` 500개. `last_npc` 는 Nova 에 없다.

`5.99-client` 에는 `db/` 가 없다 — 클라이언트 설정(`.cfg`)뿐이라 대상이 아니다.

## 매니페스트가 정답지다

`db/` 아래 `*_db.txt` 는 서버가 **무엇을 어떤 갈래로 읽을지** 직접 적어 둔 목록이다.

```
npc:db/npc/npc.txt
shop:db/npc/shop.txt
spawn:db/npc/시장_spawn.txt
```

파일 이름으로 짐작하면 틀린다. 같은 "NPC 배치"가 5.99 에선 `Spawn.txt` 이고 혼든에선
`노점_spawn.txt`·`마이소시아/아벨마을_spawn.txt` 다. 처음에 이름으로 찾다가 혼든의 NPC 배치
517개와 기술 184개를 통째로 놓쳤다.

**선언되지 않은 파일은 서버가 읽지 않는다.** 디스크에 있어도 죽어 있다는 뜻이라
`extracted/<팩>/매니페스트에없는파일.json` 에 따로 남겼다.

## 간선은 자료 안에 이미 있다

짐작할 것이 없다. 아래가 대상을 이름으로 직접 부른다.

| 간선 | 어디서 |
|---|---|
| 맵 ─워프→ 맵 | `warp/*.txt` 의 `0,출발맵,x,y,도착맵,x,y` |
| 맵 ─산다→ 괴물 | `mob/**/*_Spawn.txt` 의 `맵,괴물,마리수` |
| 맵 ─선다→ NPC | `npc/**/*spawn*.txt` |
| 상점 ─판다→ 아이템 | `npc/shop.txt` 의 `추가<TAB>아이템` |
| 스크립트 ─부른다→ 맵·아이템·괴물 | 본문의 `warp "…"`, `item_add "…"` |
| NPC ─준다→ 퀘스트 | 본문의 `@npc$=="…"`, 또는 스크립트 이름이 NPC 이름과 같을 때 |
| 퀘스트 ─가져오라/거둔다/보상→ 아이템 | `item_exist` · `item_del` · `item_add` |

## 퀘스트는 표가 아니라 스크립트에 있다

`db/` 어디에도 퀘스트 표가 없다. `#` 로 시작하는 영속변수 하나가 퀘스트 하나이고 정수값이 단계다.

```
if(@npc$=="구피"){                                    ← 누가 주나
  if(get_level(@myid)>=41){                           ← 조건
    if(#EestQuest014==1){                             ← 지금 단계
      if(item_exist(@myid,"고블린의조악한무기")>=6){     ← 가져오라는 것
        item_del "고블린의조악한무기", 6;                ← 거두어 간다
        set #EestQuest014, 2;                         ← 다음 단계
```

**중괄호 깊이로 귀속한다.** 어떤 보상이 어느 퀘스트 것인지는 그 `set` 이 어느 `if(#변수==n)`
안에 있는지로 정한다. 깊이를 셀 때 **문자열 안의 중괄호는 빼야 한다** — 대사에 색상 코드가
박혀 있다(`mes 1,"...{=q강력한 {=a이란..."`). 그냥 세면 깊이가 어긋나고, 한번 어긋나면 조건이
파일 끝까지 쌓여 엉뚱한 퀘스트에 보상 46종이 붙는다. 처음에 실제로 그렇게 나왔다.

## 스크립트를 실행하는 로직은 실행파일 안에 있다

`sources/` 의 저장소 16개에는 없다 — `item_add`·`get_myid`·`buildin_` 을 찾으면 0건이다.
그쪽은 Dark Ages(미국) 계열이라 혈통이 다르다. 소스도 없고 PE 실행파일뿐이다.

길은 혼든의 `Trap_db.txt` 주석이 알려 준다:

```
//{ buildin_trap_set, "trap_set", "siisiii" },
```

**eAthena 계열 스크립트 엔진의 함수 등록표 생김새다.** 그 표는 컴파일된 뒤에도
`{ 함수포인터, 이름, 인자서명 }` 12바이트 한 칸으로 `.rdata` 에 남는다(`i`=정수, `s`=문자열).
`.text` 를 가리키는 포인터 + 식별자 꼴 이름 + 서명 꼴 문자열이 나란한 자리를 찾으면 된다.

**인자가 없는 명령은 서명 포인터가 문자열로 풀리지 않는 팩이 있다**(Novaonline). 확실한 것만
주웠더니 그런 명령이 연달아 나오는 구간에서 표가 끊겨 `get_myid` 를 통째로 놓쳤다. 칸이
이어지는 동안 양쪽으로 늘려 잡아야 한다.

## 믿을 수 있는 만큼만

- **칸 이름은 원본 그대로다.** `내구력`·`방어력`·`콘변화` 는 db 에 그렇게 적혀 있다.
  뜻을 짐작해 붙인 이름은 없다. 확인 못 한 칸은 `fields` 에 원문대로 남겼다.
- **불렸는데 정의가 없는 이름이 있다.** 워프가 가리키는데 정의가 없는 맵, `spawn` 에만 있고
  `npc` 에 없는 NPC 같은 것이다. 숨기지 않고 vault 에 `정의없음: true` 쪽지로 남겼다.
  빠진 자료인지 오타인지는 **확인되지 않았다**.
- **아이템 대부분은 아무 데도 안 이어져 있다.** 상점에도 없고 스크립트도 안 부른다.
  그래프 그림에는 이어진 것만 그리지만 `graph.json` 에는 전부 남아 있다.
- **명령이 무엇을 하는지는 적지 않았다.** 기계어에서 뽑은 것은 "이 함수가 `+0xCC` 에 쓴다",
  "`이미 걸려있습니다` 를 참조한다" 까지다. `+0xCC` 가 체력인지는 코드가 말해 주지 않는다.
- **갈래는 증거로만 정한다.** `@name` 이면 지역변수, `#name` 이면 영속변수, 줄머리 `name:` 이면
  라벨, 명령표에 있으면 엔진 명령. 아무 증거도 없으면 `가려내지못함` 에 남긴다.

## 무엇이 어디에

```
data/server-packs/
├── <팩>/db/**            원본 (CP949 → UTF-8, 텍스트만). 커밋됨
├── extracted/<팩>/*.json 단일 출처. 커밋됨
│                          script-commands·script-command-evidence 는 서버 exe 에서 뽑은 것
│                          (exe 는 저장소 밖에 둔다)
├── vault/<팩>/           Obsidian. 커밋 안 함 — 다시 만든다
└── graph/<팩>/           graph.html · graph.json · GRAPH_REPORT.md. 커밋 안 함
```

## 함정

- **macOS 는 파일이름의 대소문자를 구분하지 않는다.** 혼든에는 `루어스은행A` 와 `루어스은행a` 가
  둘 다 있다 — 서로 다른 맵이다. vault 는 겹치면 뒤에 `~2` 를 붙이고, 빌드 때 자기 출력 폴더를
  먼저 비운다(대소문자는 보존만 되어 옛 이름이 남기 때문).
- **원본은 CP949 다.** 서버를 실제로 돌릴 때는 여기 것이 아니라 원본 zip 을 쓴다
  (`data/server-packs/README.md`).
