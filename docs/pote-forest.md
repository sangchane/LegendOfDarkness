## 2. 없는 것 — 들어가는 길

- 5.99 원본 `db/warp/Suomi_Warp.txt` 에 **수오미마을 (99,24~27) → 1존 (33,47)**, 1존 ↔ 2존 ↔ 3존 ↔ 4존 ↔ 5존·6존 워프 37줄이 있다
  (레벨 21~51, 나오는 길은 0~99).
- 그런데 5.99 의 워프 목록 `db/warp/warp_db.txt` 가 이 파일을 **싣지 않는다** — 5.99 서버에서도 포테의숲에 갈 수 없었다.
  같은 이유로 `Baeqnatop`·`Casmanum`·`Christmas`·`DraculaCastle`·`Mechanic`·`Roues` 워프 파일도 빠져 있다
  (`data/server-packs/extracted/5.99-server/매니페스트에없는파일.json`). 추출 자료 `warps.json` 에도 없어서 서버에 워프가 안 들어왔다.
- **Novaonline 팩은 같은 맵 파일(`lod6613`…`lod6620`)을 같은 연결로 싣는다** — 수오미마을 → 1존 → … → 5존·6존. 혼든 팩은 다른 판이다
  (피에트마을 → 대기실 → L·C·R 갈래 4층, 맵 파일 `lod4600~4611`).
- 5.99 `script/script.txt` 에 주석으로 남은 말: "레벨 21 … 노비스를 졸업 … 이제부터는 수오미마을과 포테의숲에서 활동" — 노비스 사냥터
  (레벨 1~22) 다음 단계로 만들어 둔 곳이다.

## 3. 구현하려면

1. `Suomi_Warp.txt` 의 포테의숲 줄을 워프 템플릿으로 들인다(가져오기 도구가 매니페스트에 없는 파일을 읽게 하거나 그 파일만 따로).
   **레벨 상한 51 은 하데스 워프에 칸이 없다**(`WarpTemplate.LevelRequired` — 하한만).
2. 모바일 맵 재료: `python3 scripts/build-client-maps.py 20263 20264 20265 20266 20267 20268 20269`.
3. 입구 수오미마을(20355)은 월드맵 점(수오미 → 40,11)으로 이미 갈 수 있다. 마을 안 건물 워프도 같은 `Suomi_Warp.txt` 에 있다 — 수오미 작업 때 함께.
4. (선택) **5존 위 오솔길 던전** — `포테의숲오솔길입장` 스크립트(5존 26·27,0 에서, 레벨 52 미만)가 캐릭터마다 맵을 새로 만들어
   (`map_create` ×3 · `warp_create` · `group_warp`) 사나운은빛늑대와 보스 자이언트맨티스를 세운다(`mob_spawn3`).
   이 명령들은 `Pack599.cs` 에 아직 없고, 두 괴물은 팩 정의(`mobs.json`)에는 있지만 서버 템플릿에는 없다. 1~6존과 따로 해도 된다.
