## 워프 절반이 죽어 있다

`warp/` 에 워프 파일이 17개인데 `warp_db.txt` 는 10개만 선언한다. 드라큐라백작의성(212줄)·
메카닉(135줄)·수오미(80줄)·크리스마스·카스마넘·베크나탑·루어스의 **566줄을 서버가 읽지 않는다**.

그래서 맵 838개 중 워프로 이어진 것이 **303개뿐**이다(혼든은 1,817 중 1,733). 팩에 남은
흔적이지 이 서버에서 실제로 갈 수 있던 곳이 아니다. 서버가 읽지 않는 `.txt` 는 모두 36개이고
`extracted/5.99-server/매니페스트에없는파일.json` 에 적어 뒀다.

## 퀘스트는 거의 없다

영속변수 60종 중 **퀘스트 꼴을 갖춘 것은 3종**뿐이다(`real`·`realmap`·`gragas`). `#real` 은
초보자 튜토리얼로 `0→1→2→3` 네 단계다. 이벤트는 **아예 없다** — `item/Event/` 가 없고
`item/Cash/` 가 있지만 그건 캐시상점이지 이벤트가 아니라 세지 않았다.

## 엔진에 `last_npc` 가 없다

`last_npc` 와 `rand2` 는 `Novaonline.exe` 에 **문자열조차 없다**(Nova 에는 `rand` 만 있다).
그래서 이 팩의 스크립트는 `@npc$=="…"` 로 상대를 확인하는 일이 한 번도 없다 — 쓸 수가 없어서다.
대신 스크립트 이름 자체가 NPC 이름이다(`초보자도우미1`). 퀘스트와 NPC 를 이름이 같을 때만 이은
이유가 이것이다.

## 기계어에서 붙인 증거

401개 전부를 뜯었다 (`scripts/disasm-script-commands.py`).

| | |
|---|---|
| 문자열을 참조하는 것 | 71 |
| 구조체에 쓰는 것 | 156 |
| 갈래를 가르는 helper | 44 |
| 같은 문자열을 쓰는 무리 | 11 |
| 같은 자리에 쓰는 무리 | 48 |
| 증거가 하나도 안 붙은 것 | **7** |

### 문자열로 갈린 무리

| 문자열 | 명령 |
|---|---|
| `이미 걸려있습니다.` | 20개 — `belra` `colama` `dell` `enare` `defens` `antimagic` `hide` `immortal` … |
| `buildin_skill_exist: invalid name!` | `skill_add` `skill_add2` `skill_del` `skill_del2` `skill_exist` |
| `buildin_item_add: invalid name!` | `item_add` `group_item_add` |
| `%s: %s` | `mob_say` `mob_say2` `pet_say` `user_say` |
| `몸이 얼어 움직일수 없습니다.` | `item_pickup` `mobsor_delay` `mobsor_delay2` |
| `잠이 쏟아져 옵니다.` | `item_pickup` `mobnar_delay` `mobnar_delay2` |

첫 줄 20개는 이름이 원작 마법 그대로다(벨라·코마·델·에나레). `buildin_del: invalid name` 처럼
함수 이름이 오류 문자열에 박힌 것도 있어 eAthena 혈통이 코드 안에서도 확인된다.

### 오프셋으로 갈린 무리

| 쓰는 자리 | 명령 |
|---|---|
| `+0xCC` | `get_hp_add` `set_hp_add` `set_vita` `set_vital` `group_hill` `pet_rescue` |
| `+0xE0` | `money_add` |
| `+0xF0` | `char_disguise` `hide` `pet_rescue` `set_state` `set_state1` |
| `+0x24` | `item_clear` `item_pickup` `mob_clear` `npc_del` `set_pass` `warp_create` |

거의 모든 명령이 훑는 자리(`+0x4 +0x8 +0xC +0x10 +0x14 +0x20`)는 인자를 꺼내는 틀이라 뺐다.
**그 자리가 무엇인지는 코드가 말해 주지 않는다** — 이름에서 그렇게 읽힐 뿐이다.

### 손으로 읽은 것 하나

`money_add` (0x446A4B, 51 명령어):

```asm
mov  eax, [edx+20]        ; st->rid
mov  eax, [세션배열 + eax*4]
mov  edi, [eax+52]        ; → 플레이어
...
call conv_num             ; 정수 인자 하나
add  [esi+0xE0], eax      ; ★ 더한다 (mov 가 아니다)
call 통보
```

**더하는 것**이라 `money_add -5000` 이면 깎인다. 이 함수 안에 상한·음수·오버플로 검사는 없다.

## 남은 것

- 증거가 안 붙은 명령 7개: `end` `get_myid` `get_totem` `goto` `group_exist` `group_master` `legend_del`.
  문자열도 갈래 helper 도 없는 짧은 함수라 더 알려면 손으로 읽어야 한다.
- 각 명령이 **무엇을 하는지**는 적지 않았다. `+0xCC` 가 체력인지, `belra` 가 무엇을 거는지는
  확인되지 않았다.
