# 계정 등록 및 kruna 결제 방법.

안녕하세요? 오늘은 1달 계정등록 쿠폰을 결제하는 법을 알려드릴까 합니다. 모두 결제하는법을 원하시는 것 같아서 ㅎㅎ...스크린샷별로 별도로 표시하여 쉽게 알아보실 수 있도록 작성했습니다. 쉬운 등록 하시고 즐거운 게임하세요^-^;   스크린샷 01[[[CONTENT-ELEMENT-0]]] 처음 화면입니다. 이 화면은 저희카페 대문에서 ACCOUNT를 클릭해주세요. 직접 홈페이지에서 클릭하셔도 됩니다.   스크린샷 02[[[CONTENT-ELEMENT-1]]]이전의 ACCOUNT를 클릭하셨다면 현재 화면으로 넘어오셨을 겁니다. 저 두개중에서 아무거나 클릭해 주세요.   스크린샷 03[[[CONTENT-ELEMENT-2]]] 그럼 이런 화면이 뜨실겁니다. 저는 현재 세팅을 다 해논 것이구요.첫번째 클립은 게임 종류입니다. 당연히 Dark Ages 선택해 줍니다.두번째 클립은 결제 방식의 종류입니다. 무조건 Credit Card/Paypal/Rixty 선택해 줍니다. 그외에 결제 못하시는거 알잖아요.세번째 클립은 결제 물품의 종류입니다. One Month 즉 한달등록쿠폰과 그외에 한국어둠 캐쉬에해당하는 Kruna결제가 있습니다.적절히 선택한 후 Proceed를 눌러줍니다. 여기서는 한달 등록쿠폰이니 저렇게 설정한 후 진행하겠습니다.   스크린샷 04[[[CONTENT-ELEMENT-3]]]다음으로 동의 절차입니다. 그냥 저대로 Yes에 클릭하고 진행해 줍시다.   스크린샷 05[[[CONTENT-ELEMENT-4]]]자~ 결제 종류 선택화면이 나옵니다. Rixty는 저도 모르겠구요. Credit card나 Paypal둘중 하나로 해야합니다.그런데 페이팔 추천해요. 크레딧카드로하면 에러나더라고요 저는. 3만원 쌩돈 날렸습니다. 기록도 남고 쉽고 편한페이팔쓰세요. 진짜 편합니다. 여기서는 페이팔만 다루겠습니다. 페이팔 클릭해주세요.   스크린샷 06[[[CONTENT-ELEMENT-5]]]스크린샷에 표시된 그대로 클릭해 주시면 됩니다.   스크린샷 07[[[CONTENT-ELEMENT-6]]]페이팔 계정자체가 생성할때 Email주소를 ID로 생성하게 됩니다. Have a Paypal Account? 클릭하시면저렇게 이메일과 페이팔 패스워드 입력이 가능한 창이 나와요. 빨간부분에 페이팔계정(이메일)을 적으시고파란부분에 비밀번호를 적으신후 로그인 눌러주시면 됩니다.   스크린샷 08[[[CONTENT-ELEMENT-7]]]네 다음 화면입니다. 이렇게 로그인을 하시게 되면 페이팔에 연동된 자신의 정보(이름,주소)와 연동된 카드정보 그리고 이메일이 뜹니다.(저기 나와있는 메일주소로 쿠폰번호가 발송됩니다) 저기위에 Pay now보이시죠. 지불하세요! 누르시면 지불됩니다.(ㄷㄷ 클릭한번에)아 저위에 검열은 당연한 겁니다. 제개인정보가 있으니까요.   스크린샷 09개인정보 공개로 인한 삭제.네 결제가 완료 되었습니다. 어때요? 정말 간단하죠? 페이팔 계정을 사용할경우 이렇게나 간단히 등록이 가능합니다^-^;자신 카드사의 SMS수신동의에따라 문자로 결제가 됬다고 오는분도 있고 안오는분도 있으실 겁니다.   스크린샷 10[[[CONTENT-ELEMENT-8]]]네 제 페이팔 계정이자 실제 이메일주소인 nin_hao@naver.com 으로 쿠폰번호가 왔습니다.검열은 필수죠 저거아직 살아있는 코드거든요.ㅋㅋㅋㅋ  이상입니다. 이후에는 쿠폰번호를 어떻게 등록하고 계정과 연동하는지 쓰겠습니다^^; 수고하셨어요.   ps. 등록하면 DA의 재미가 달라집니다. 흐흐흐...해보세요...그럼 알게되실거에요
