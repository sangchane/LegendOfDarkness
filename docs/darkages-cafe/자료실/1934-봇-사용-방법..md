# 봇 사용 방법.

안녕하세요​봇 사용방법에 대해 간략하게 알려 드려볼게요.​[ 실행하기 ] 봇을 다운로드 받으셨다면실행파일에 커서를 두고 마우스 오른쪽을 눌러 관리자 권한으로 실행 시켜 줍니다.※ 매번 실행시 마다 관리자 권한으로 실행 해주세요.​[ 설정 하기] 제일 먼저 DA가 저장된 경로의 파일을 먼저 설정 해줘야 합니다.상단에  OPTIONS 탭을 누르고
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    Choose DA path를 누릅니다.
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    browse를 눌러 DA 실행파일을 눌러 줍니다.저의 경우 아래 경로에 저장 되어 있네요.C:\Program Files (x86)\KRU\Dark Ages\Darkages.exe
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    [게임 켜기]launch - da를 누르면 게임이 켜집니다.multiple에서 원하는 숫자를 적어서 launch를 누르면 여러개의 게임을 한번에 켤수 있어요.
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​[general]​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    [SPELLS - SELF]각종 마법 (힐, 공격마법, 저주)를 설정 할수 있음.힐-> 캐릭터 별로 체력 퍼센트 이하로 떨어지면 힐을 하도록 선택 할수 있음.(사용 가능한 SPELL만 표기 됩니다. 마법을 배우지 않으면 표시 되지 않음.)​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​[SPELL- MOSTER]
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​[SKILLS]몬스터에게 가기.기본공격스킬사용스킬사용 조건걸기 (이모탈시 크래셔등.)
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​[ITEMS]골드나 아이템을 줍고설정된 아이템을 버리도록 할수 있습니다.TRINKET및 탈것 변신등도 여기서 설정 가능.
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​[HUNTING]시간당 획득하는 경험치계산.더블등 시간당 경험치를 계산해줍니다.(10분마다 갱신됨)
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​[SPEECH]호르라마, 119, 힐등 필요할때 자동으로 말해주게 설정.(사용할일 없는거 같아요)​[WALK]
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​[TASKS]
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    [MISC.]
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    [SETTING]위 설정한 값을저장 하고 불러 올수 있어요​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​[나머지 REALISTIC, TEST, PACKETS는 몰라도 됩니다.]마법 사용 딜레이 설정, 케릭터 꾸미등을 미리 해볼수 있어요.​혹시 추가 설명이 필요하다 싶으면 수정 추가 할게요
