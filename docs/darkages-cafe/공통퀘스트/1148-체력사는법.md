# 체력사는법

[[[CONTENT-ELEMENT-0]]]일단 서큐버스 머리카락을 준비해 줍니다. [[[CONTENT-ELEMENT-1]]]서큐버스 머리카락을 넣으면 저런멘트가 나오는데 저기서 Yes를 눌러줍시다. [[[CONTENT-ELEMENT-2]]] 이제 지나가는 사람에게 죽여달라고 합시다. 저 상태가 되면 사람들이 신나게 저한테 달려옵니다.[[[CONTENT-ELEMENT-3]]] 죽으면 이곳으로 오는데, 절대 뮤레칸을 클릭하면 안됩니다. 그럼 그냥 마을로 돌아가져요.. [[[CONTENT-ELEMENT-4]]]이곳으로 이동후 앞으로 쭉 들어가 줍시다. [[[CONTENT-ELEMENT-5]]]들어가면 탭을 키고 저기서 왼쪽이나 오른쪽으로 이동합니다. 전 오른쪽 구멍으로 들어가니 이동되더군요. [[[CONTENT-ELEMENT-6]]]들어오면 신전이 나오는데 여기서 왼쪽이 체력사는곳 ,오른쪽은 마력사는곳 입니다. [[[CONTENT-ELEMENT-7]]]여기서 두번째 창을 클릭하시면 경험치가 나가면서 체력이 올라갑니다.[[[CONTENT-ELEMENT-8]]]주의할점은 여기서 3번째 I descend를 누시면 마을로 가집니다. 체력을 다올린후 누르시길 바랍니다.
