# 승급 투구 퀘스트(도적 도가 전사)

도적과 도가 전사는 승급 시 투구를 주지않기때문에 퀘스트를 완료하여야합니다. 먼저 grassy field로 간후 서있는 npc에게 말을걸면 그래시필드안에잇는 몬스터별로 각각2마리씩잡아오라고합니다. 갓승급분들은 혼자가시면 몹젠이빠르고 몹수도많아 힘드니 그룹을 맺거나 다른 비격분들의 도움을 받으시길바랍니다. 여차저차 2마리씩 5종류였나 4종류였나 잡고가서 다시 대기실에있는 npc와 대화를하게되면 일기장과 승급투구를 받게됩니다.
