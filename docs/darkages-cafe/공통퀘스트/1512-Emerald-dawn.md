# Emerald dawn

[[[CONTENT-ELEMENT-0]]]먼저 수오미 태번에 있는 바드에게 "adventures" 라고 타이핑합니다. 대화를 마친 후 수오미 스킬사범(스킬사범인지 무기마스터 즉 대장장이인지 아직 모르겟음)에게 "emerald knights"에대해 물어본 후 샤인우드 대기실로 향합니다.샤인우드 대기실에서 sw5까지 엠블렘을 찾을때까지 이리저리돌아댕깁니다. 대기실이 맵이가장좁아서 베스트라고 하네요.찾은 후 다시 수오미 스킬사범에게 가서 "Emerald knights"라고 타이핑하면 퀘스트가 완료됩니다. 추가적인 네크로맨서 오더. 로그 오더. 드루이드 오더는 아마 타이핑해서 나오는 대화에서 말해주는것같습니다. 참고하시어 타이핑하고 퀘스트를 진행하면서 나오는 대화하나하나를 유심히 읽어보는게 좋을것같습니다.추가적으로 네크로맨서오더도 일기장을 받을수있으며 로그오더는 받을수없다고합니다. 그리고 랜덤골드와 랜덤 경험치를 지급한다고합니다.   보상으로는 일기장" found emerald knight insignia"과 랜덤 골드 경험치를 준다고합니다. 그 네크로맨서 오더 또한 일기장애새겨지며 로그오더와 일기장을주지않으며 드루이드오더는 보상이없다고합니다. 차후에 클리어한 후에 추가적인 것들은 적도록하겠습니다.
