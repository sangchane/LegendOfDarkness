# *맵 이동

한국어둠의 월드맵은 어느 월드맵으로 나가도 어디든 갈 수 있습니다. 하지만 외국어둠은 그렇지 않은데요, 초보분들이 가장 많이 묻는것중 하나가 마을들(뤼케시온, 운디네등등)을 어떻게 가는지 질문하십니다. 외국어둠에서 맵 이동을 알려드릴게요.  [[[CONTENT-ELEMENT-0]]] 외국어둠을 처음 생성 하시거나 직업을 가지셨을때, 밀레스에서 시작하실겁니다. 다른 마을에 가고싶다. 하시면, T를 누르시고 'M'을 찾으시면 됩니다.(붉은원) 일단 밀레스에서 나갑니다. [[[CONTENT-ELEMENT-1]]] 월드맵이 나와야하는데 Village Way(마을통로)가 일단 나옵니다.*마을통로는 마을마다 다 있습니다. 당황하지 마시고 마을통로에서 나갑니다.[[[CONTENT-ELEMENT-2]]] 월드맵이 나옵니다. 루어스, 뤼케시온, 오렌, 수오미, 운디네, 타고르등등 활성화가 안되어있죠? 당황하지 말고, Pravat Cave로 갑니다.(붉은사각형) [[[CONTENT-ELEMENT-3]]] 이곳이 Pravat Cave입니다. 사람들이 많이 왔다갔다하고 잠수 타고, 한마디로 '죽대'같은 공간이예요. 주로 이곳에서 외국인과 소통을 많이하죠. 다른 마을로 가기위해 오른쪽으로 꺾습니다.[[[CONTENT-ELEMENT-4]]] 들어가주죠,[[[CONTENT-ELEMENT-5]]] 처음 월드맵과 달리 갈 수있는 곳이 생겼죠? 여기중에 볼일 있으신분이 계시면 볼일을 보시고, 아직 활성화되지 않은 마을에 가시고싶은 분은, loures(루어스)로 가줍니다.(붉은사각형)  [[[CONTENT-ELEMENT-6]]] loures(루어스)를 클릭하시면 루어스 마을통로가 나옵니다. 루어스에 볼일이 있으시면 그대로 들어가주시고, 다른마을로 가시려면 다시 나옵니다.[[[CONTENT-ELEMENT-7]]] rucesion(뤼케시온), tagor(타고르마을)등 또 여러곳이 활성화 되었죠? 이중에 볼일이 있으신분은 볼일 보시고, 오렌마을로 가시고싶은분은 Lynith Beach를 클릭해줍니다. [[[CONTENT-ELEMENT-8]]] Lynith Beach통로입니다. 오렌마을이 목적지라면 다시 나와줍니다. [[[CONTENT-ELEMENT-9]]] Oren Island(오렌섬)이 활성화 되었죠? 이제 수오미, 운디네에 가봐야겠죠?[[[CONTENT-ELEMENT-10]]] 밀레스에서 나와, 북쪽에있는 Abel(아벨)로 갑니다. [[[CONTENT-ELEMENT-11]]] 아벨에 도착하셨으면 역시, 아벨 마을통로가 나옵니다. 안으로 들어갑니다.[[[CONTENT-ELEMENT-12]]] 안으로 들어가면 아벨마을이 나옵니다. T를 누릅니다.[[[CONTENT-ELEMENT-13]]] 저 배(붉은원)까지 갑니다.
