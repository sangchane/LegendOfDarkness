# 코마디움 만들기

필요마법 :       [[[CONTENT-ELEMENT-0]]]               Beothaichdeum준비물    : 포도 2개 , 체리 1개   [[[CONTENT-ELEMENT-1]]]동의우드랜드 2존에 가서 입구 옆에 있는 나무 근처에 가서 마법 Beothaichdeum를 사용하고 움직이면 팝업이 나타납니다.[[[CONTENT-ELEMENT-2]]]만들고 싶으면  "beaothaich beaothaich beaothaich!" 라고 소리지르랍니다2번을 선택합니다.[[[CONTENT-ELEMENT-3]]]인벤토리에 Red Potion 3개(코마디움)를 획득하게 됩니다. 가끔씩 썩은 체리, 썩은 포도, 와인을 만들기도 합니다.[[[CONTENT-ELEMENT-4]]] Red potion을 첫번째 슬롯에 놓고 Potion Lore 스킬을 사용하면 beothaich deum으로 바뀌게 됩니다.[[[CONTENT-ELEMENT-5]]] 아참 ard ioc deum(엑스쿠라눔)도 Lore스킬을 사용하기전엔 Red potion 입니다.
