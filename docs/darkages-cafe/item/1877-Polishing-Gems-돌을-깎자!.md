# Polishing Gems: 돌을 깎자!

                                    구매할 수 있는 젬에는 총 3가지가 있는데직자는 스펠을 배우기위해서 Beryl Fragment와 Ruby Fragment가 많이 필요합니다!​한번 구매해볼까요? ​​구매를 완료하셨다면
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    젬들은 Raw형태로 존재하는데 (이는 감정이 안된 돌들을 의미합니다)​​자 gem polishing이라는 스펠을 써서 깎아보도록 합시다!
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​​​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    gem polishing 스펠을 시전한뒤​​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    땅바닥에 동전을 떨구면 (1원)​​​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    메뉴가 나옵니다.​여기서 팁!uncut종류의 젬들은 alone을 누르셔서 진행하는게 좋습니다.안그러면 한번에 그냥 fragment에서 flawed 또는 finished fragment가 될 수 도 있어요!​Alone클릭!​다 깎으셨다면 Appraise라는 스킬을 써서 1번 아이템창에 있는 조각을 감정하시면
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​짜잔 uncut ruby가 만들어졌습니다!​​참고로 uncut fragment를 은행에다가 안맡기거나 땅에 안떨구고 인벤토리에 놔둔채로 진행하시면​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    다음 단계의 fragment (flawed ruby)가 될 수 있으니 꼭 맡기거나 땅에 잠깐떨구고 polishing이 끝나면 다시 줏어드시면 됩니다!​​그러면 finished fragment는 어떻게 깎나요?​일단 마을에서 registered (정액제)된 도적을 찾아봅시다.​​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    저기에 Tazz라는 도적이 보이는군요!​​아까와 같이 gem polishing시전 -> 동전떨구고 -> 이번에는 assistance를 눌러줍시다.​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    그리고 assistant의 이름으로 Tazz라는 도적의 아이디를 입력하시면​​성공적으로 polishing을 할 경우에는​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    ​
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    Flawed fragment나 finished fragment가 될겁니다.​Flawed fragment일 경우에는한번더 assistance를 클릭하여 진행하시면
                            
                        
                    
                                
                    
                        
                                
                                    
                                        
                                    
                                
                        
                    
                
                
                    
                        
                            
                                    flawed fragment를 finished ruby로 제련하는게 가능합니다.!!!​​​​결론: 직자는 심신을 다스리며 돌을 깎아야 스펠들을 배울수가 있다!귀찮으면 다른 유저에게 구매하면 된다!
