# 제가 미국어둠 시작하려는데..

팁과Q&A에 각 직업마다 들어가보면스텟/육성 글이 있습니다.여기에 각 전직군들 특성이랑 추천도가 있는데 참고하시면 될것같아요개인적으로 핫한 격수는morrior(도가->전사), pure warrior(순수전사), pronk(직자->도가), progue(직자->도적)등이 있는데도가가 들어간 직업군은... 정말 힘듭니다.도가키우기가 진짜 장난 아니에요그래서 처음하시는분들에겐 거의 비격을 추천하지만뭐 본인이 원하신다면 순수전사(pure warrior) 추천합니다.
