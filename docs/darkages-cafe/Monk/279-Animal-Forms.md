# Animal Forms

무도가의 길을 걸으셨다면 4개의 동물 Form중에 하나를 선택 하실수 있습니다.Form을 선택하면 일기장에 기록되며 스킬과 마법을 배우게 됩니다.Form을 선택하기 위해서는 모든 스텟과 레벨이 적어도 5 는 되어야 하며 당신을 가르쳐줄 사람이 필요합니다.혼자 배우고 싶다면 모든 스텟이 10 은 넘어야 합니다.
