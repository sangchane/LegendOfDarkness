# *gem polishing(보석가공)

도적은 '보석'을 가공할 수 있습니다. 보석은 마법/기술재료에 쓰입니다. 보석은 4단계의 등급으로 분류되는데, fragment(파편) -> uncut(원석) -> flawed(흠이있는) -> finished(완벽한) 의 등급으로 나뉩니다. {예) ruby fragment(루비파편), uncut ruby(루비원석), flawed ruby(흠있는루비), finished ruby(완벽한 루비)}    gem polishing(보석가공)을 하기전에, 2가지의 스킬을 배우셔야 합니다. [[[CONTENT-ELEMENT-0]]] 보석가공하는데 gem polishing이 없으면 안되겠죠?[[[CONTENT-ELEMENT-1]]] 그리고 미확인 아이템을 감정하는 appraise 스킬도 필요합니다.     [[[CONTENT-ELEMENT-2]]] 두 스킬이 준비되었으면 일단 보석을 구하러 가야겠죠? pravat cave의 구멍안으로 들어갑니다. [[[CONTENT-ELEMENT-3]]] 들어가면 저렇게 귀걸이처럼생긴 보석들이 널부러져 있어요. 만약 없다면 안의 몹을 잡으면 나옵니다.(생각보다 약할거예요.) [[[CONTENT-ELEMENT-4]]] 몇개 건지셨으면 이제 polishing(가공)을 합니다. 1번창에 가공하고자 하는 보석을 놓아주세요. 저는 제일 낮은단계인 fragment네요. [[[CONTENT-ELEMENT-5]]] 그리고, gem polishing을 시전해 줍니다. [[[CONTENT-ELEMENT-6]]] 그리고 발밑에 1원을 떨어뜨려줍니다. [[[CONTENT-ELEMENT-7]]] 그러면 팝업창이 뜹니다. Assistant와 Alone이 있는데, Assistant는 그룹한 사람이 한명 필요합니다. Assistant를 하게되면 그룹한사람 아이디를 적고, 그룹한사람이 자신의 아이디를 적어야 실행됩니다. 보석강화성공률이 높아요. Alone은 그냥 혼자하는겁니다. Assistant보다 보석강화성공률이 적죠. [[[CONTENT-ELEMENT-8]]] 저는 혼자니 alone을 선택했어요. 깨졌네요.[[[CONTENT-ELEMENT-9]]] 다시 시도했어요. 실패는 했지만 보석이 깨지진 않았어요.[[[CONTENT-ELEMENT-10]]] 드디어 성공했어요. 성공하게되면 성공멘트와함께 경험치가 오르면서 Raw ~(미확인보석)으로 바뀝니다. [[[CONTENT-ELEMENT-11]]] Raw보석(미확인보석)을 1번창에 넣고 Appraise 스킬을 사용하면, 감정이 됩니다. finished(최상급)이 떳네요.ㅋ[[[CONTENT-ELEMENT-12]]] 이렇게 보석가공을 하면 일기장에도 남습니다.    보석강화는 하다가 깨지거나, 성공했으나 등급이 안 올라가거나, 성공하거나. 이렇게 3가지 결과가 나옵니다. Assistant를 하면 Alone보다 성공확률이 더 높구요. 보석의 종류는 다양합니다.(Coral, Beryl, Ruby, Talos, Hy-brasyl등등..)   finished보석을 만들어서 팔거나,(coral, beryl, ruby,talos 같은경우는 개당 10~20만원정도) 마법/기술 배우는데 쓰면 적절할거예요.
