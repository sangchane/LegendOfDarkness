어둠의 전설 모바일 — 화면 6장

와이어프레임에 정해진 화면 전부를, 원작 클라이언트가 실제로 그린 그림 위에 세웠습니다. 새로 그린 그림은 없습니다. 각 화면은 눌러볼 수 있습니다 — 로그인은 두 칸을 채워야 버튼이 열리고, 대화는 다음 문장으로 넘어가고, 전투는 공격할수록 상대 체력이 줄어듭니다.
