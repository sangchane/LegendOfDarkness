모바일 UI 시안 — 원작 4.51 테마 (채택안)

안 C를 전 화면에 편 것이다. 규칙은 하나다 — 틀·제목·확정 단추는 원작 돌, 읽고 고르는 속은 평평하게. 체력·마력 아이콘은 원작 구슬을 납작하게 줄여 그림 파일 없이 그린다(.pip). 바탕은 일부러 금빛 바닥이다 — 지금 코드가 “이 바닥 위에서 글자가 사라진다”고 적어 둔 그 바닥이라 읽히는지가 여기서 판정된다. 3안 비교는 three-ways.html.

규칙 — 이대로 만든다

무엇왜
돌이 두 가지다 어두운 돌 dlgback.epf 평균 rgb(40,36,38) — 넓은 면: 창 바깥 틀 · 제목줄
밝은 돌 msgsm.epf 평균 rgb(125,119,108) — 작은 면: 확정 단추 · 공격 버튼 · 고른 탭		 원작도 둘을 그렇게 나눠 쓴다. 밝은 돌에 작은 글자를 넓게 얹으면 먼저 무너진다 — 안 B 와 첫 시안에서 실제로 안 읽혔다
돌을 안 쓰는 곳목록 · 격자 칸 · 입력칸 · 보조 단추 · 방향판무늬 위 글자는 작은 화면에서 먼저 무너진다
글꼴제목줄·확정 단추만 세리프, 나머지 산세리프, 숫자는 font-mono자릿수가 흔들리면 값이 안 읽힌다
글자 색은 돌이 정한다 어두운 돌 위 → 밝은 글자 #abab9f + 그림자
밝은 돌 위 → 음각 #100f0b + 아래 rgba(255,255,255,.6) 1px		 음각은 밝은 돌에서만 성립한다. 어두운 돌에 음각을 쓰면 글자가 사라진다
속#0f0f0f 96% · 칸 #1f1f24금빛 바닥 위에서 글자가 살아남는 유일한 값
체력·마력#c8783c · #5a6fa8 — 원작 구슬에서 뽑았다창에는 색이 없으므로 강조색은 구슬에서만 나온다
아이콘납작한 원 하나(.pip, 18px) — 그림 파일 없음원작 구슬(86×85, 16단계)은 18px 로 줄이면 뭉갠다
치수틀 5 · 속 12 · 틈 8 · 누르는 곳 44 이상 · 모서리 12모서리는 속에만. 돌 틀은 각져야 원작처럼 보인다
체력 표시머리 위 = 백분율 막대(맞을 때만) · 위 판 = 정확한 숫자(늘)같은 것을 두 번 그리지 않는다

배치는 하나도 안 바꿨다. 지금 클라이언트가 이미 잡아 둔 자리(위 상태판 · 기록 줄 · 방향판 · 공격 둘레 부채꼴 · 아래에 붙는 창 · 18자리 고리)를 그대로 쓴다. 바뀌는 것은 재질뿐이므로 손대는 파일은 mobile/client/src/Greybox.cs 와 그것을 부르는 곳들이다.
