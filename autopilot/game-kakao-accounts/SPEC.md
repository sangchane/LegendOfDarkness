# SPEC: 앱 카카오 로그인 단순화 + 내 캐릭터 관리 (L 변경 · 2026-10-11)

## 배경
`autopilot/game-kakao-login/SPEC.md` 를 배포한 뒤 사용자: 「홈페이지에서 접속할때만 5948 입력이 필요하고 앱에서는 카카오톡 로그인하고
게임 계정 선택해서 로그인하게 해주면되는거야 이건 복잡하잖아」 · 「앱에서는 카카오톡 로그인 기능 지원해서 게임 아이디 선택수정추가 가능하게
해서 관리가능하게 하면돼」 · 수정 = **삭제·생김새 바꾸기** · 「옛 케릭터는 지금 내 카카오톡 아이디에 모두 이어주면되고 … 이어주는건 내가 추후에 지정」.
홈페이지(카카오 가입 → 5948 → 허가 → 내려받기)는 이미 그렇게 돈다 — 바꾸지 않는다.

## 제안 변경
1. **서비스 — 6자리 번호 없앰** (사용자 「6자리 인증은 필요없다니까 홈페이지에 가입된 카카오톡 아이디로만 플레이 가능하게하면되잖아」)
   (`scripts/ops/ability-ops-service.py`, `docs/app-login.*`): `bind` 는 번호를 만들지 않고 `redeem` 은 묶였으면 바로 ok(허가된 사람만 token).
   끝 화면은 늘 「로그인됐습니다. LOD 앱으로 돌아가세요」. 앱이 code 를 보내도 무시.
2. **서비스 — 내 캐릭터 목록** `POST /api/kakao/characters {"token"}` → 게임 표 확인(game-check 와 같은 판단: 서명·만료·허가) →
   200 `{"characters":[{"name","level","path","gender","hairStyle","hairColor"}]}` — `LOD_CHARACTER_DIR` 의 `*.json` 중 `KakaoId` 가
   그 회원번호인 것(이름순). 대기·거부 403 `{"status"}`, 그 밖 401. 읽기만 한다.
3. **게임 서버 — 비밀번호 칸 동사** (우리 갈래, `KakaoLogin.cs`·`LoginServer.cs`). 새 opcode 없이 0x02 를 쓴다:
   - `표|look` + 이름: 그 캐릭터 주인이 표의 회원번호이고 접속해 있지 않으면 0x00 → 이어지는 0x04 가 **머리 모양·머리색만** 바꿔 저장
     (성별·직업은 무시 — 성별 전용 옷이 깨지므로). 아니면 거절 문구(`다른 카카오 계정의 캐릭터입니다.` · `접속 중인 캐릭터는 바꿀 수 없습니다.` · 없는 캐릭터).
   - `표|delete` + 이름: 같은 조건이면 캐릭터 파일을 `database/server/aislings-deleted/<이름>-<UTC yyyyMMddHHmmss>.json` 로 옮기고
     0x00 + 「지웠습니다.」, 아니면 거절. **지우지 않고 옮긴다**(되살리기 = 파일을 되돌려 놓기).
   - 캐릭터 자물쇠(`AislingStorage.LockFor`) 안에서 다시 읽고 판단. 같은 기계(평문)·카카오 끔은 지금과 같음. `표|<옛비밀번호>` 잇기는 서버에 남긴다(앱이 안 씀).
   - `NotLinked` 문구 → 「아직 카카오에 이어지지 않은 캐릭터입니다. 관리자에게 이어 달라고 해 주십시오.」
4. **앱** (`mobile/src/Lod.Mobile.Core` + `mobile/client`)
   - 표가 있으면 첫 화면 = **내 캐릭터 목록**(서비스 2): 줄마다 이름·레벨·직업 + [들어가기] [생김새] [삭제] · 아래 [새 캐릭터] [카카오 로그아웃].
     이름 입력 칸·「옛 캐릭터 잇기」 없앰. 목록이 비면 「캐릭터가 없습니다 — 새 캐릭터를 만드세요」. 403/401 이면 지금처럼 표를 지우고 처음으로.
   - [삭제]: 「<이름> 을(를) 지웁니다. 되돌리려면 관리자에게 말해야 합니다.」 확인 한 번 → 0x02 `표|delete` → 목록 새로.
   - [생김새]: `CreateScreen` 을 바꾸기 모드로(이름·직업·성별 고르기 숨김, 지금 머리 모양·색으로 시작) → 0x02 `표|look` → 0x04 → 목록으로.
   - 카카오 로그인 기다림 화면의 6자리 칸·번호 보내기를 없앤다.
5. **옛 캐릭터 이어 두기(한 번)** — 클라우드에서, 접속 안 한 캐릭터 중 주인이 없고 봇 이름(`CompanionBots`·`EcoBots`)이 아닌 것에
   `KakaoId` = 사용자 회원번호(`kakao-users.json` 의 관리자). 손님 주몽애자도 포함(사용자 「모두」) — 옮겨 주기는 뒤에 사용자가 지정.
   고치기 전 `aislings` 를 통째로 백업.
