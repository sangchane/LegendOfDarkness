## 할 것
1. 서버: 사용자 2026-10-08 「애초에 옷을 입건 버프 디버프가 걸려있건 본체력을 알 수 있으니까 거기에 맞춰서 사지도록」 — 세오·칸의 벗기 검사를 빼고 본체력·본마력(`_MaximumHp`·`_MaximumMp`, 장비·버프 뺀 것)으로 값을 매기고 더한다. 생성기 `build-pack-npcs.py` `BLOCK_PATCH`(`_body_stats`) + `Pack599.Call` `get_bodyvita`·`set_bodyvita`·`get_bodymana`·`set_bodymana`. `get_basevita` 는 기술 위력에도 쓰여 그대로. `get_ac` 는 넣지 않는다(포인트신·2차할까는 빠진 명령이 있어 막힌 채가 안전). `sleep` → 0(밀리초, 한 대답 안에서 바로).
2. 알맹이: `Vitals.Bank`(99 쌓인 경험치 = (ExperienceToGo≪32)|Experience — 앱 윗줄과 같은 식) · `EcoVitality.Plan(최대, 쌓인 경험치, 한 번에, 상한)` 몇 번 살 수 있나(n번째 값 = (최대 + 한 번에×n)×500).
3. 봇(`EcoRunner`): 장보기 끝에, 99이고 한 번이라도 살 수 있으면(본체력 = 최대 − 입은 장비 몫으로 어림) → 세오신전으로 → 입은 채 세오 「체력을 산다.」 → 횟수 → 최대 체력이 오르거나 「부족」까지. 샀으면 한 시간 뒤, 못 샀으면 5분 뒤 다시. 성직자는 쌓인 경험치의 절반으로 칸에서 마력을 먼저 산다. 사건 `vitality`(전·후 최대 체력·마력, 쓴 경험치).
4. eco 기록 `exp` 는 99에서 쌓인 경험치(위 32비트까지).
