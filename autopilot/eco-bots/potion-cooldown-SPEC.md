# 물약 쿨타임 2초 — SPEC (M, 2026-10-08)

사용자: 「보통 이런 자동물약은 물약 먹고 다음 물약 먹는 시간 사이에 딜레이가 있는지부터 좀 찾아봐 마냥 먹을수고 없고 마냥 아랫사냥터로 갈수도 없잖아」 · 「모바일 게임 장보를 찾아야지」 → 고른 것 「2초」 · 「서버 규칙 — 사람·봇 모두」.

## 왜
99 봇이 뤼케시온해안에서 상급체력포션 30개를 20초 남짓에 다 마신다(초당 1.5개). 서버 0x1C 에 간격 검사가 없다(`GameServerHandlers.Format1CHandler`).
모바일 MMORPG 조사: 오딘 1초 · 검은사막M 정령수 3초 · 미르4·나이트 크로우는 있음(초 모름). 물약으로 못 버티면 대개 그냥 죽게 둔다.

## 규칙
- 체력이나 마력을 채우는 물건(템플릿 `HealthRestore`·`ManaRestore` ≠ 0 — 물약·음식 모두)은 **2초에 한 번**. 체력·마력이 쿨타임을 함께 쓴다(「물약 먹고 다음 물약」).
- 2초 안에 또 쓰면 서버가 거절하고 물건은 줄지 않는다. 한 줄로 알린다.
- 자동 물약(`AutoPotion` — 앱·대신 사냥·생태계 봇)은 마신 것이 확인된 뒤 2초를 기다린다. 동료 봇(`CompanionBrain.DrinkGap`)은 1.5초 → 2초.

## 완료 기준
1. 격리 서버: 물약 둘을 잇달아 쓰면 두 번째는 체력이 안 오르고 개수 그대로, 2초 뒤에는 먹힌다.
2. 알맹이: 마신 것이 확인된 뒤 2초 안에는 다음 물약을 고르지 않는다(답 없는 요청은 지금처럼 2초 뒤 다시).
3. 알맹이 시험 전부 · 물약 쓰는 서버 시험(Pack599Consumable · Frozen · CompanionComa) 통과.

## 안 할 것
사냥터 고르기 · ⑤ 99 뒤 경험치로 체력 사기 · 물약 무게·개수 한도 · 걷기 다시 켜기(이것 배포 뒤 따로).

## 배포
서버 규칙이라 다음 `cloud-server.sh deploy`(접속자 끊김 — 알리고) 때 서클별 아이템 값과 함께. 봇·대신 사냥은 같은 배포에서, 앱은 `ios-build.sh install`.
