## 배경
사용자(2026-10-11): 「사망하면 접두사 붙은 아이템 사라지게 하는 패널티 부활시키고 그 후에도 무장 다시 잘 갖추는지 테스트 … 현재 캐릭터들도
본인 서클에 맞게 장비를 잘 갖추었는지 보고 맵 번호로 말하면 내가 어딘지 모르거든 … 접두사 붙은 아이템이 아닌 아이템과 금전은 죽은 좌표 위에
쌓이는데 이건 사망 후 10분간은 사망한 케릭터 본인만 다시 먹을 수 있어 … 무도가랑 전사는 세토아, 메투스, 칸 … 도적은 세토아, 셔스, 칸 …
사제라는 표현 성직자로 싹다 바꿔라 성직자랑 마법사는 성장할때는 로오,이아,칸 … 99가 되면 모든 직업이 칸이나 체력이 500 이상 상승하는 아이템
혹은 무장이 같은 부위보다 방어력을 많이 높여주는 아이템을 우선순위로 … 경매장에서도 시세가 반영되게 되는지까지가 중요 테스트 포인트」.
확인 답(같은 날): 장비+가방 모두 · 사라지는 것 = 신 이름 접두사 전부 + 수토풍화 속성 목걸이·벨트, **크리스탈목걸이는 바닥에** · 시세 = 실제 거래가 기반.

1. **사라짐 표시 바로잡기(자료)** — 생성기 `scripts/gen/items/build-death-perish.py`(--쓰기 없으면 미리보기): 장비 템플릿 중

   → `Perishable` 켬, 그 밖의 장비는 `Perishable` 끔. 서버는 이 표시 하나만 본다.
2. **사망 패널티(서버)** — `SendToHell` 의 `DeathDropsItems` 갈래를 새 규칙으로(옛 `CursedSachel` 은 안 씀): 장비+가방 모두,
   `Perishable` → 없앰 · 나머지 아이템과 금화 → 죽은 맵·좌표 바닥에, 주인(죽은 캐릭터)만 10분 줍기(`Cursed`+`AuthenticatedAislings`, 풀림은
   아이템별 시각 — 괴물 드랍 3분은 그대로). 금화도 같은 잠금. 설정 `DeathDropsItems=true`(틀·클라우드). 동료 봇은 서버가 다시 입힌다(`CompanionKit`).
   사망 사건을 활동 기록에 남김(잃은 것·떨군 것 이름·금화). 시험(격리 서버): 죽음 → 사라짐/바닥/10분 잠금/10분 뒤 남도 줍기.
3. **봇 장비 점수(직업·서클)** — `EcoShopping.Score` 를 직업·레벨 인자로: 무장(−AC)은 늘 + ·

   **99: 모든 직업 마법방어·HP≥500·같은 부위보다 높은 무장** 최우선. 가중치 상수는 `Tuning.cs`. 죽은 뒤 맨몸 → `Shop`(경매·가게)으로 다시 갖춤.
   시험: 직업·레벨별 고르기 단위 시험 + 죽음 뒤 다시 갖추기(격리 서버에 생태 봇 하나).

   살 때 우선순위가 높을수록(점수 이득) 더 높은 값까지 입찰(상한 지금처럼 보유 금화 비율). 시험: 시세 계산·입찰 상한 단위 시험 + 클라우드 며칠 관찰
