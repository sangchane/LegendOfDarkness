# 보석 · 분해 · 제작 NPC · 팔찌 — SPEC (M, 2026-10-08)

사용자(10-08): 「드랍에 넣고 상점에서는 접두어가 없는것만 판매해, 분해로 나올 보석은 아이템 레벨이 99이상인 경우에 고가 4종도
낮은 확률로 획득 가능하게하고 중급은 아이템 레벨에 따라 확률이 상승하는 구조로 만들고 사냥터는 중급보석은 현재 99레벨 던전에서만
나오도록 하고 고가는 추후에 승급던전에서 나오도록 할게 업그레이드도 제작 npc 통해서 진행하자」 · 「배포는 작업 모두 완료 후 하자」.

## FRAME
- 누구: 사냥해서 쓸모없는 장비가 쌓이는 사람(그리고 봇). 문제: 장비는 팔거나 버릴 뿐이고, 보석 8종은 얻을 길이 없어 크리스탈목걸이·홀디트링을 올릴 수 없다. 접두 팔찌 40종은 드랍에서 빠져 있고 기본 팔찌는 서버에 없다.
- 성공: 가방에서 장비를 분해하면 레벨에 따라 보석이 나오고, 99 사냥터에서 중급 보석이 떨어지며, 제작 NPC 가 보석으로 속성 목걸이·홀디트링을 만든다. 팔찌가 드랍과 상점에 있다.
- 안 할 것: 고가 보석 사냥터 드랍(승급 던전 때) · 세피라링 강화(쇠조각·문스톤 없음) · 흑진주·다이아몬드·색보석 · 분해 확률 설정화.

## 통로
- 앱 → 서버 `0xF1 10` 가방 칸(1). 서버가 장비인지·있는지 다시 보고, 빼고, 굴려서 준다. 결과는 서버 알림(얻었습니다 / 아무것도 나오지 않았습니다).
- 앱: 소지품에서 장비를 누르면 뜨는 정보 상자의 [장착] 옆 [분해](장비일 때만) → 「○○ — 분해할까요?」 [분해][취소]. 판을 띄운 때의 칸·이름을 붙잡아, 그 사이 다른 칸을 누르거나 정렬해도 물은 것만 분해한다. (위 줄 켜고 끄는 단추는 세로 360 폭에서 닫기 X 를 밀어내 버렸다.)

## 완료 기준(차례대로)
1. 팔찌 드랍: 생성기 고침 → `build-drop-variety` → `build-potion-by-level` → `build-drop-cap` 쓰기, 접두 팔찌가 사냥터 목록에 있다. 기존 드랍 시험 통과.
2. 기본 팔찌 4종 템플릿 + 보석상여주인 물목. 상점 시험 통과.
3. 서버 `Gems`(굴림·분해·사냥터) + `0xF1 10` + `monsterexp.cs` — 굴림 단위 시험, 분해 격리 서버 시험, 99 맵 목록 시험.
4. 메린 NPC — 크리스탈목걸이 + 루비 → 화염의크리스탈목걸이, 홀디트링 + 레드자스퍼 4개는 거절(격리 서버 시험).
5. 앱 [분해] — 알맹이 패킷 시험, 클라이언트 빌드, 화면 한 장.
6. 리뷰 1회 → 커밋 → 배포 한 번에(앞 묶음 경매장 필터·가방·자동사냥과 함께 — 서버 deploy, 앱 iPhone install·윈도우 release).
