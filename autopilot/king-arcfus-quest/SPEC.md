# 아벨해안 킹아크퍼스 퀘스트 — SPEC (M, 2026-10-11)

출처: 디시 어둠의전설 갤 「뉴비들을 위한 퀘스트 공략 #26 - 아벨해안의 무법자 - 킹 아크퍼스」 https://m.dcinside.com/board/darkages/2919 (스크린샷 20장).
원작 흐름: 딜란·레토 대화 → 포스파늄 4 → 붉은진주 → 3존 비밀의 방(함정찾기) 브라토 → **해저의팬던트** · 터틀/크래커/퐁퐁이 껍질 2개씩 → 대장장이 →
**대지의인장** → 4-C 암초에 무도가가 서면 그룹이 **외딴길**(코마밭) → 숨겨진길 잡몹 2방 → 5직업 자리 → **거대문어의본거지**(가짜, 문어다리) →
브레한 → 밀레스신전 제단에 문어다리 → 문어 7마리(성직자는 게껍질 5) → **원한의에센스** → 다시 4-C → **킹아크퍼스의본거지**(진짜) → 미레 → **세줄황금반지**.

## FRAME
- 누구: 41레벨 이상(3서클) 손님. 문제: 아벨해안은 사냥만 있고 원작 3서클 이벤트가 없다.
- 성공: 혼자서도(그룹이면 함께) 원작 순서대로 팬던트·인장 → 가짜 보스 → 원한의에센스 → 진짜 보스를 거쳐 세줄금반지와 전설을 받는다.
- 안 할 것(사용자 10-11 「앞부분 대화형 부분은 패싱 · 5인 아니어도 진행 가능」): 딜란·레토·브레한 대화와 타이핑 · 포스파늄·붉은진주 · 무도가 필수·5직업 자리 서기 · 함정찾기(숨은 칸은 그냥 밟으면 됨) · 봇이 퀘스트 하기.
