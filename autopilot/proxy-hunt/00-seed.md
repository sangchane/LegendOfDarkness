# Seed — 대신 사냥(proxy-hunt)
버전: v1.0

- 원문: 「앱이 뒤로 가거나 끊겨도 서버가 캐릭터를 내보내지 않고 앱의 자동 사냥 설정(반경·포션·기술·마력 상한)대로 대신 사냥, 다시 접속하면 앱이 넘겨받음」(NEXT.md 2026-10-05 밤).
  사용자 답(2026-10-05): 방식 = **클라우드 대리 접속**(동료 봇처럼 같은 기계에서 알맹이 그대로) · 최대 시간 = **앱에서 설정, 기본 2시간** · 무음 재생 되돌림.
- 서비스 유형: 기존 게임(모바일 MMORPG)의 기능 하나 — 서버 확장 + 헤드리스 프로그램 + 앱.
- 주 도메인 / 인접 도메인: 게임 클라이언트 자동화 / 로그인 인증(대리 접속 열쇠).
- 감지된 제약: 서버·대리 프로그램은 같은 클라우드 기계(161.33.43.117) · 서버 .NET(Hades) · 앱 Godot 4.6 C# · iOS 는 뒤로 가면 게임 루프가 멈춤(c70e16d4 실측).
- 로드할 블라인드스팟 프로파일: 모바일 · 인증.
- 강도: lite — 사유: 1인 운영·사용자 소수, 기존 시스템의 bounded 변경. 단 로그인 인증을 건드리므로(L 변경 신호) A4 위협모델은 STRIDE 전수.
- 해석한 것(사용자가 말하지 않았는데 내가 정한 것, 틀리면 비싼 순):
  1. 대리 접속은 **자동 사냥이 켜져 있을 때만** 맡는다. 꺼져 있으면 지금처럼 끊기면 내보낸다.
  2. 앱이 뒤로 가면 **앱이 스스로 접속을 끊고** 바로 넘긴다(서버가 180초 기다리지 않게). 그래서 앱으로 돌아오면 다시 로그인(저장 계정 자동 로그인)한다.
  3. 대리 접속 열쇠는 **한 번 쓰고 버리는 표**(서버가 만들고 대리 프로그램만 읽음). 비밀번호는 서버·대리 프로그램 어디에도 남기지 않는다.
  4. 시간이 다 되거나 위험(포션·회복 없음)·죽음이면 **그 자리에서 로그아웃**(귀환 안 함).
  5. 다시 접속한 앱이 대리 접속을 밀어내고, 앱은 자동 사냥을 다시 켠다. 대신 사냥한 결과는 한 줄로 보여 준다(분·경험치·금화).
