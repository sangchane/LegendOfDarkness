# PRD — 대신 사냥
버전: v1.1

> 진입 사전조사 — 정량: 서버 무응답 끊김 30초(`GameServer.cs:89-107`), 무접속 사냥 관행 8시간(01). 정성: iOS 는 뒤에서 앱을 멈춘다 — 앱 안 해결은 불가(c70e16d4 실측). 사용자 영향: 폰을 잠가도 사냥이 이어지고, 열면 몇 초 안에 다시 내 손으로.

## 배경
자동 사냥을 켜 두고 앱을 뒤로 보내면 30초 안에 서버가 캐릭터를 내보낸다. 무음 재생으로 앱을 살려 두는 시도는 실패했다(되돌림). 사용자는 클라우드에서 대리 프로그램이 내 캐릭터로 접속해 앱과 같은 판단으로 사냥하는 방식을 골랐다(02 Q2). 근거·감사 `01-recon.md`.

## 용어
- **맡김 설정**: 앱이 서버에 보내는 대신 사냥 설정 한 덩어리(사냥 반경·회복 %·포션 규칙·줍기·막대 기술·마법·중심 칸·시간).
- **넘김 표**: 앱 접속이 끊길 때 서버가 대리 프로그램에 남기는 작업(캐릭터 이름·일회용 열쇠·맡김 설정·끝 시각).
- **대리 접속**: 대리 프로그램이 넘김 표의 열쇠로 들어온 세션.

## 제품 목표
1. 자동 사냥 중 앱이 뒤로 가거나 끊겨도 정한 시간 동안 사냥이 이어진다.
2. 다시 앱을 열면 끊김 없이 내 손으로 돌아오고 그동안의 결과를 안다.

## 유저 스토리
- US-1 (P1) 플레이어로서, 자동 사냥을 켜 두고 폰을 잠그면 정한 시간만큼 캐릭터가 같은 설정으로 계속 사냥하길 원한다 — 자는 동안에도 레벨이 오르게.
- US-2 (P1) 플레이어로서, 앱을 다시 열면 대리 사냥이 멈추고 내 앱이 이어받으며 「대신 사냥 N분 · 경험치 +X · 금화 +Y」를 보길 원한다.
- US-3 (P2) 플레이어로서, 설정 창에서 대신 사냥을 끄거나 시간(기본 2시간)을 고르길 원한다.

## 엣지케이스
- Given 앱이 뒤로 갔다 2초 만에 돌아옴, When 대리가 아직 안 들어옴, Then 앱 로그인이 넘김 표를 지우고 대리의 열쇠 로그인은 거절된다(FR-004·007).
- Given 앱이 돌아왔는데 대리가 동시에 열쇠로 들어오는 중, When 앱이 이미 접속해 있음, Then 열쇠 로그인 거절 — 앱은 밀려나지 않는다.
- Given 대리 사냥 중 포션이 떨어지고 회복 기술이 없음, When `AutoHunt` 가 Stop, Then 대리가 그 자리에서 접속을 닫는다.
- Given 대리 사냥 중 캐릭터 죽음(혼수), Then 접속을 닫는다(살리기 시도 없음).
- Given 대리 프로그램이 멈춤(프로세스 죽음), Then 서버가 끝 시각 + `ProxyGrace` 에 대리 세션을 끊는다. 새로 띄운 대리는 이미 쓴 열쇠로 다시 들어가지 못한다.
- Given 맡김 시간 10시간을 보냄(조작), Then 서버가 `ProxyHoursMax` 로 자른다.
- Given 원격 주소에서 열쇠로 로그인, Then 거절(루프백만).
- Given 옛 앱(종류 7 모름), Then 맡김 없음 → 지금과 같이 내보냄.
- Given 넘김 표가 `TokenTtl` 안에 안 쓰임, Then 서버가 지운다.

## 성공 기준
- SC-001: 자동 사냥 중 앱 접속을 끊으면 `HandoffDelayMax` 안에 같은 캐릭터가 대리 접속으로 월드에 있고 괴물을 친다(격리 서버 시험).
- SC-002: 대리 접속은 맡김 시간(시험에서는 분 단위로 줄여)이 지나면 접속을 닫고, 서버는 프로그램이 멈춰도 끝 시각 + `ProxyGrace` 에 끊는다.
- SC-003: 열쇠 로그인은 루프백·이름 일치·미사용·유효 시간 안·캐릭터 미접속일 때만 성공하고, 나머지 다섯 경우는 모두 거절된다.
- SC-004: 대리 접속 중 앱으로 로그인하면 앱이 들어가고 대리는 끊기며, 앱에 결과 한 줄(분·경험치·금화)이 온다.
- SC-005: 대리 판단은 앱과 같은 알맹이를 쓴다 — 같은 시야를 주면 앱 연결부와 대리 실행기가 같은 `HuntStep` 을 낸다(알맹이 시험).
