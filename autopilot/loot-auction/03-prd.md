# PRD — 그룹 전리품 룰렛 · 경매장
버전: v1.1

## 배경
그룹 사냥(결정 19·20)에서 전리품은 줍는 사람 몫이라 사냥하지 않는 성직자는 금화·물건을 못 얻고, 봇은 희귀품까지 NPC 에게 판다(`EcoShopping.ToSell`, 01).
사용자는 그룹 전리품을 룰렛으로 나누고, 필요 없는 것을 팔거나 와우식 경매장에 올리게 하길 원한다(00). 경매장은 사람·봇이 함께 쓴다(결정 17).
와우 규칙(보증금·입찰·즉시 구매·5% 수수료·유찰)을 따르고 우편 대신 「받을 것」 칸을 둔다(01). 디아블로3 처럼 시장이 사냥을 대신하지 않게 봇 올림에 상한을 둔다(01).

## 용어
- **룰렛**: 서버가 같은 맵 파티원마다 1~ROLL_MAX 수를 굴려 가장 높은 이에게 물건을 주는 것.
- **룰렛 물건**: `Flags` 에 Equipable 이 있거나 `Upgrades > 0` 이거나 `ItemVariance` 가 있는 물건. 그 밖은 **돌림 물건**.
- **올림**: 경매에 물건을 거는 것. **입찰**·**즉시 구매**·**보증금**·**수수료**·**유찰**(입찰 없이 기간이 끝남)은 와우와 같은 뜻.
- **받을 것**: 경매장이 캐릭터에게 맡겨 둔 물건·금화(낙찰품·판매 대금·유찰품·밀린 입찰금·취소품·넘친 룰렛 금화).
- **상점가**: NPC 상인이 사 주는 값 `ShopPricing.Offer`(= `Template.Value` / 1.6, `H/Types/ShopPricing.cs:7`) × 묶음 수 — 와우 보증금의 「상인 판매가」에 해당.

## 제품 목표
1. 그룹 사냥 전리품이 파티원 모두에게 공정하게 돌아간다(성직자 포함).
2. 사람과 봇이 와우식 경매장에서 물건을 사고팔아 NPC 상점 밖의 경제가 생긴다.
3. 언제든 끄고 되돌릴 수 있다 — 물건·금화를 잃지 않고.

## 유저 스토리
- **US1 (P1)** 파티원으로서, 그룹 사냥 중 장비가 떨어지면 자동 룰렛으로 누가 가져갈지 보고 싶다 — 다툼 없이 공정하게. (독립 시험: 4인 그룹 처치 → 룰렛)
- **US2 (P1)** 플레이어로서, 경매장 메뉴에서 물건을 찾아 입찰하거나 즉시 사고, 내 물건을 올려 팔고 싶다. (독립 시험: 올림 → 즉시 구매 → 받기)
- **US3 (P2)** 생태계 봇 운영자로서, 봇이 필요 없는 희귀품을 경매에 올리고 자기에게 나은 장비를 사길 원한다 — 경제가 살아 있게.
- **US4 (P2)** 운영자로서, 경매장·룰렛을 끄고 남은 물건·금화를 주인에게 돌려줄 수 있어야 한다.
P1 만으로 성립: 룰렛 + 사람이 쓰는 경매장.

## 불변식
- **INV-1 물건 보존**: 경매에 올린 물건은 어느 순간에도 정확히 한 곳(경매장 또는 한 사람의 받을 것 또는 가방)에만 있다.
- **INV-2 금화 보존**: 모든 경매 조작 뒤 (관련 캐릭터 금화 + 맡긴 입찰금 + 맡긴 보증금(진행 중 Listing.Deposit 합) + 받을 것 금화)의 변화 = −(이번 조작에서 몰수된 보증금 + 수수료).
- **INV-3 복제 없음**: 캐릭터 파일과 경매장 파일은 따로 쓰이므로 둘을 한꺼번에 쓸 수는 없다. 순서를 「사건 기록 한 줄(flush) → 내주는 쪽 저장 → 받는 쪽 저장」으로 고정해,
  서버가 어느 지점에서 꺼져도 물건·금화가 **두 곳에 생기지는 않는다**. 그 사이에 꺼져 생긴 유실은 사건 기록의 마지막 줄로 운영자가 되살린다(07 런북).
  돈을 내주는 쪽: 올림·입찰·즉시 구매는 캐릭터(가방·금화에서 빼고 곧바로 캐릭터 저장), 받기는 경매장(받을 것에서 빼고 경매장 저장).
  **내주는 쪽 저장이 실패하면**(지금 `AislingStorage.Save` 는 예외를 삼킨다 — 성공 여부를 돌려주게 고친다) 메모리 변경을 되돌리고 조작을 거절한다. 주기 자동 저장과 겹치지 않는지는 BUILD 첫 작업에서 확인한다.

## 엣지케이스
- Given 파티원 4명 중 1명은 다른 맵, When 룰렛 물건이 떨어지면, Then 같은 맵 3명만 굴린다.
- Given 이긴 이의 가방이 가득, When 룰렛이 끝나면, Then 물건은 그 사람 발밑에 떨어지고 다른 파티원은 줍지 못한다.
- Given 혼자 사냥(그룹 없음), When 처치하면, Then 지금처럼 바닥에 떨어진다.
- Given 같은 경매에 둘이 동시에 즉시 구매, When 서버가 처리하면, Then 하나만 성공하고 다른 쪽은 「이미 팔렸습니다」, 금화는 빠지지 않는다.
- Given 입찰한 이가 접속을 끊음, When 다른 이가 더 높게 입찰하면, Then 밀린 입찰금은 받을 것으로 가 다음 접속 때 받는다.
- Given 받을 것에 금화 5억, 들고 있는 금화가 상한 − 1억, When 모두 받기, Then 1억만 받고 4억은 남는다.
- Given 서버가 즉시 구매 처리 도중 꺼짐, When 다시 켜면, Then 물건은 경매장 또는 사는 이 받을 것 중 한 곳에만 있다(INV-1).

## 성공 기준
- **SC-001** 격리 서버: 4인 그룹이 룰렛 물건을 떨군 괴물을 잡으면 같은 맵 파티원 모두가 룰렛 결과를 받고, 가장 높은 수를 낸 한 명의 가방에만 그 물건이 들어간다(10회 반복 모두).
- **SC-002** 격리 서버: 그룹 처치 금화 합 = 나눈 금화 합(1전도 사라지거나 생기지 않음), 각 파티원 몫의 차이 ≤ 파티원 수 − 1.
- **SC-003** 격리 서버: 올림 → 입찰 → 더 높은 입찰 → 즉시 구매 → 모두 받기 한 바퀴에서 INV-1·INV-2 가 매 단계 성립하고, 파는 이의 순수익 = 즉시 구매가 − ⌊즉시 구매가 × AUCTION_CUT⌋.
- **SC-004** 격리 서버: 경매가 걸린 채 서버를 멈췄다 켜면 올린 것·입찰·받을 것이 그대로다. 동시 즉시 구매 20쌍에서 성공은 쌍마다 정확히 1.
- **SC-005** 앱(맥, 실제 로그인): 「설정」 옆 「경매장」을 눌러 네 탭이 열리고, 올림 → 다른 계정 즉시 구매 → 받기가 화면에서 끝난다(세로·가로 화면 사진 각 1장).
- **SC-006** 클라우드 생태계 봇 24시간: 봇 올림 ≥ 1 · 봇 구매 ≥ 1, 어느 봇도 ECO_AUCTION_MAX 를 넘지 않음, 경매 사건 기록에 INV-2 위반 0.
- **SC-007** 되돌리기 스크립트를 격리 서버 자료에 돌리면 올린 물건·받을 것이 모두 주인 은행으로 가고 개수·금화 합이 같다.
