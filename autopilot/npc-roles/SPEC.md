# NPC 역할 아이콘 — SPEC (M, 2026-10-08)

사용자(10-08): 「그럼 미니맵에서 찾기 쉽게 처리해줘 지금 마을마다 어느 npc가 뭐하는지 잘 모르겠던데 직관적으로 ui 적용해줄래」.

## FRAME
- 누구: 마을에 들어와 상점·은행·제작 NPC 를 찾는 사람. 문제: 미니맵은 NPC 를 모두 같은 색 점 하나로, 월드에는 이름조차 없이 그린다. 하는 일은 길 찾기 창 목록을 하나씩 눌러야 안다.
- 성공: 미니맵·길 찾기 창·월드에서 NPC(와 상점 건물 문)가 하는 일을 아이콘 모양으로 바로 알아본다. 같은 역할은 어디서나 같은 아이콘.
- 안 할 것: NPC 자리 옮기기 · 대화 내용 바꾸기 · 경매장(위 줄 단추라 NPC 아님) · 미니맵 크기·배치 바꾸기.

## 역할(생성기 `build-client-guide.py` 가 서버 템플릿·대본에서 정한다 — 짐작하지 않는다)
| 역할 | 근거 | 아이콘 · 색 |
|---|---|---|
| 무기 · 방어구 · 장신구 · 물약 · 잡화 | 상점(`shop1`·`shop2`) 물목의 과반이 무기(자리 1) · 갑옷(2) · 장신구(3~13) · 소모품. 과반이 없으면 잡화 | 칼 · 방패 · 반지 · 물약병 · 자루 — 상점 금빛 |
| 은행 | `Banker` | 동전 — 금빛 |
| 제작 | `gem_crafter`, 대본이 `item_add`+`item_del` | 망치 — 주황(체력 구슬) |
| 퀘스트 | 대본 `legend_add` | 느낌표 — 노랑 |
| 전직 · 기술 · 체력 · 능력치 | `Class Chooser`·`set_class(_sub)` · 가르침 · `set_basevita/mana` · `set_str` | 별 · 책 · 하트 · 더하기 — 파랑(마력 구슬) |
| 미용 · 게시판 · 이동 · 안내 | `set_hair` · `call_func` · `warp` · 그 밖 | 가위 · 판 · 화살표 고리 · 말풍선 — 밝은 흙빛 / 이동은 출구 강조색 |

상점·은행·메린·전직사범은 템플릿 키로 정하고, 5.99 대본은 전직 > 퀘스트 > 기술 > 체력 > 능력치 > 미용 > 제작 > 게시판 > 이동 > 안내 차례로 처음 맞는 것(밀레스신전 선진은 전직·가르침·퀘스트·물건 주고받기를 다 해 제작을 아래로). 건물(출구 너머 맵)은 안에 선 NPC 들의 역할을 차례대로 — 마을·사냥터로 나가는 문에는 붙이지 않는다.

아이콘은 계열 색으로 채운 원판 + 어두운 모양(반지름 6~7 에서 테두리·가는 선이 엉겨 뭉개져 바꿈). 미니맵 8 · 길 찾기 창 10 · 이름표 7. 이동은 흙빛(출구 강조색 = 제작 주황과 같아서).

## 자료
- `guide.txt` 새 줄 `role <맵> <x> <y> <역할>`, `room` 줄 끝에 `|<역할,역할>`. 알맹이 `MapGuide` 가 `MapSign.Role` · `MapRoom.Roles` 로 읽고, `TabMap.Markers` 가 NPC·출구 표식에 역할을 붙인다.

## 화면
- 미니맵: NPC 는 역할 아이콘(점 대신), 상점 건물 문은 안의 역할 아이콘.
- 길 찾기 창: 지도 위 같은 아이콘 · 아래 NPC 목록 칩에 아이콘 + 「역할 · 이름」 · 팝업 제목에 역할.
- 월드: NPC 머리 위 이름표(아이콘 + 이름), 그림 없는 NPC 표지는 역할 아이콘, 건물 문 「→ 수오미무기점」 표지 앞에 아이콘.

## 완료 기준
1. 생성기 → `guide.txt` 역할 줄(모든 NPC), 건물 줄 역할. 무기점 가이=무기, 갑옷점 아돌=방어구, 보석상여주인=장신구, 오리아나=은행, 메린·별셋제작도우미=제작.
2. 알맹이 읽기·표식 시험 통과(기존 시험 포함).
3. 미니맵·길 찾기 창·월드 사진(세로) — 마을 한 곳에서 아이콘이 겹치지 않고 읽힌다.
4. 리뷰 1회 → 커밋 → 앱 배포(아이폰 install · 윈도우 release, 서버는 그대로).
